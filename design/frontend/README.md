# 早期前端原型（历史参考）

本目录保留 MVP 阶段的静态原型、演示数据、截图和本地预览工具。它不代表当前生产界面或下一轮交互要求。

视觉规范、交接和原型验收文档已归档，入口见 [早期原型文档](../../docs/archive/frontend-prototype-2026-10-19/README.md)。当前开发请从 [00-开发入口](../../docs/00-开发入口.md) 开始，生产前端位于 `packages/web/`。

如需查看历史原型，可打开本目录 `index.html`，或从仓库根目录运行：

```powershell
node design/frontend/serve.mjs
```
