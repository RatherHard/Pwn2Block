# Pwn2Block 前端视觉与交互原型

本目录执行 `docs/archive/mvp-2026-10-16/10-前端美术与页面设计任务书.md`，交付一套中文深色终端工作台。它是可交互的设计参考，不是生产前端、真实 Blockly 编辑器或 VM。所有执行和判题结果均为显式预设的公开合成样例。

## 打开

直接双击本目录的 **index.html** 即可使用，无需安装或构建，无 CDN、字体下载或网络 API。

推荐从仓库根目录运行：

```powershell
node design/frontend/serve.mjs
```

浏览器打开 **http://127.0.0.1:4174/**。`Ctrl+C` 停止；可传入端口，例如 `node design/frontend/serve.mjs 4180`。服务器仅监听本机，仅提供本设计目录。这个命令不启动生产服务，也不读取题库。

底部蓝灰色的 **“原型演示”** 下拉框选择状态。状态也可通过 `?state=won` 等参数直接打开；参数只选择预设，不表示服务端判定。顶部“调试模式 / 判题结果”切换产品模式。底部状态选择器不进入生产页面。

## 建议检查路径

1. 在默认工作台观察 buffer / saved_bp / ret_addr。折叠题面，打开提示并逐条揭示。
2. 打开“视图”菜单，勾选显示/隐藏，拖动排序或用上下箭头；在工作区按 `Ctrl+↑ / Ctrl+↓` 滚动一个槽位。
3. 在画布把 padding 从 16 改为 24，确认出现“已过期，请重新编译”，试运行、payload 单步和提交禁用。编译后恢复。
4. 切到“编译错误与定位”，点击输出区的定位按钮，再“应用修正样例”并编译。
5. 单步、试运行、运行 N 步、后退、撤销、重置，查看等待反馈与不同操作说明。这里选择预设投影，不执行输入的指令数。
6. 切到“调试满足条件”，确认仍能调试，没有 flag。再选择四种判题结果，拖动时间线，观察地址与寄存器变化；点击“回到调试”，确认原调试状态保留。
7. 检查 I/O 与隐藏内存、会话失效、加载、空态和长文本状态。

## 状态目录

| 参数 | 内容 |
|---|---|
| `default` | 默认调试，栈 + 指令，已连接与未连接积木，三条编译动作 |
| `io` | 自由内存 + 条件 I/O；隐藏、可见、未映射对照；stdout ASCII/hex、stdin 已读 |
| `registers` | 所有样例寄存器、ZF/CF/SF、变化符号与公开指针链 |
| `uncompiled` / `stale` | 未编译 / 编辑导致旧产物过期 |
| `error` / `limit` | 参数错误 / 编译资源上限错误，定位与修正入口 |
| `waiting` / `complete` | 请求等待锁 / 动作已执行完；等待样例可手动展示返回 |
| `satisfied` | 调试已满足条件，可继续操作，不显示 flag |
| `won` / `incomplete` / `failed` / `rejected` | 四种正式结果、动作回放、返回调试；拒绝动作不改变投影 |
| `debug-failed` / `exited` | 调试异常 / 已退出，执行禁用，回退入口可用 |
| `expired` / `network` | 会话失效 / 网络错误，重新开始保留画布并清空历史 |
| `no-challenges` | 无可用题目、无会话、等待工具箱与刷新列表入口 |
| `loading` / `empty` | 加载占位 / 无可见视图与仅开始积木 |
| `history` | 最近 64 条指令回退窗口已用尽 |
| `hints` | failures 达到 2，自动揭示到第二条提示 |
| `long` | 长题面、96 个动作、长错误说明的内部滚动 |

切换**判题结果预设**不会修改演示的调试投影、画布参数、产物状态或请求历史。判题展示自己的固定提交样例。切换**其他调试预设**则有意载入该场景；“重置演示”恢复默认布局与调试状态。已揭示提示按题目保存在 `p2b-design:hints:design-stack-lab`，不与生产存储混用；存储禁用时退化为本次打开内有效。`?state=hints` 是演示专用的阈值重演入口。

## 已实现与模拟范围

真实可操作：菜单、题面折叠、提示与本地记忆、视图显隐、拖动/按钮排序、快捷键滚动、地址定位、hex/ASCII 搜索、对齐偏移、函数定位、寄存器与示例 flag 复制、工具箱展开、积木选择与定位、参数样例切换、产物过期、等待禁用、时间线拖动与模式切换。

模拟：编译只在 16/24 两组手写动作样例之间选择；工具箱不创建积木；执行、指令回退、会话重建与判题只选择手写公开快照。输入 N 只用来展示 `step.count` 请求意图，不会驱动 VM；24 字节参数样例也不驱动内存模拟。点击“提交判题”固定选择 `incomplete` 反馈，其他 verdict 由原型控制条选择，绝不通过地址或字节推导通过。原型动作对象附带的 `blockId` 只作演示关联，不是请求契约。

截图展示的 flag 始终标记 **“示例，非真实 flag”**。没有读取 `private.json`、环境变量或参考解法。可见地址布局参考现有公开 `packages/web/src/fixtures/sample.ts`，文字与状态快照为本目录合成数据；没有复制真实参考解法。

真实 Blockly 拖拽、完整键盘导航、真实编译/API 联调、多题切换和服务端验收不在本次实现中；接入责任见 `handoff.md`。本目录不能用于勾选 08 中的 G3 或真实八步闭环。

## 重跑验证

在已有仓库依赖和本机 Edge 的环境运行：

```powershell
node design/frontend/verify.mjs
node node_modules/eslint/bin/eslint.js design/frontend/*.js design/frontend/*.mjs
```

脚本自行启动随机端口预览并关闭，只更新本目录的截图和验证记录。没有增加任何依赖或更改锁文件。本次用 Edge/Chromium 实测 1440×900、1280×720、1920×1080；实际通过数量以 `verification.md` 为准。浏览器截图已生成，完成了几何、交互和页面错误断言；**未进行人工视觉审查**，未验证 Firefox、Safari 或真实屏幕阅读器。
