## 0. D1 只搭骨架：不勾选任何未验收条目

- 本目录在 D1 只建立**文件结构、需求映射与真实可执行的字段白名单守卫**，不宣告任何安全项已验收。

- 未验收的条件用 `describe.skip` + `it.todo` 承载：**跳过就是跳过**，不写任何会让 CI 假通过的占位断言，
  也不把 mock、样例或 shared 层单测当作真实接口验收（08 §1：「mock 通过不算真实接口验收」）。
- 勾选规则（08 §1）：`[ ]` 未验收，`[x]` 已验收。进行中/阻塞/待集成写交接记录。
  **未验收的条目一律不勾选，不允许因为「看起来没问题」或「后续会做」而预先勾选。**
- 核心检查必须在**真实对象**上跑：真实 `@pwn2block/engine`、真实 `@pwn2block/server`（Fastify 实例）与真实首题
  `challenges/ret2win`。样例对象只用于 D1 的契约守卫。
