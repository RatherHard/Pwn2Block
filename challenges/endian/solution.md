# endian 参考解法

考点是**把 8 字节的目标值按小端序写进内存**，再让程序把它读成一个 64 位数值。

程序在 `vuln`（0x400000）只有两条指令：

1. `mov rax, [rbp+0x8]`：把 `RBP+0x8` 处的 8 个字节读成一个值，写进 `RAX`；
2. `syscall 60`：退出。

`RBP` 的初值是 0x7fffff00，所以这次读的是栈上的 **0x7fffff08**（栈视图里的「目标槽」）。
目标值 `0x1122334455667788` 占 8 个字节，按小端序（最低位字节放在最低地址）依次是：

```
0x7fffff08: 88 77 66 55 44 33 22 11
```

对应的十六进制串是 `8877665544332211` —— 正好是数值书写顺序的逆序。

用 `write_bytes` 从 0x7fffff08 写下这 8 个字节，再 `step` 一次让程序执行那条 `mov`：
`RAX` 变成 0x1122334455667788，成功条件（`reg_eq RAX`）成立。想看到程序退出，
也可以把 `step` 换成 `run`。

payload 从初始状态回放：地址与字节都是字面量，不含任何读运行时状态的构造。

```json
{
  "actions": [
    { "type": "write_bytes", "addr": "0x7fffff08", "hex": "8877665544332211" },
    { "type": "step", "count": 1 }
  ],
  "expectedVerdict": "won",
  "note": "0x1122334455667788 的小端表示 + 让程序读一次"
}
```
