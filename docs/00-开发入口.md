## 代码入口

当前画布以 `archive/canvas-logic-2026-10-30/节点功能逻辑重构.md` 为功能基准，使用 Lit + HTML 节点 + SVG 连接。此前两份画布方案中的列表、字典、流程序列和分组交互不再定义当前产品行为。完整规则与验证映射见 [节点功能逻辑重构实现与验收](archive/canvas-logic-2026-10-30/节点功能逻辑重构-实现与验收.md)。

| 工作内容 | 主要入口 | 修改时关注 |
|---|---|---|
| 图文档、节点与连接 | `packages/shared/src/canvas/logic-model.ts` | 五种标量、三类连接、同类包络；变量只有名称 |
| 校验、全局定义与执行 | `logic-validate.ts`、`logic-runtime.ts`、`logic-values.ts`（同目录） | 首次赋值确定类型、只读派生变量、无环依赖、执行预算 |
| 布局、吸附与编辑 | `packages/web/src/canvas/logic-editor.ts` | 最近单一候选、内部吸附纳入包络、移动/删除附件、不可变编辑 |
| 节点库、手势与侧栏 | `packages/web/src/components/logic-canvas.ts`、`logic-canvas-library.ts` | 分类分页与常驻预览；右键菜单复用历史；草稿与已提交图分离，一次拖动一次撤销 |
| 图形与样式 | `logic-canvas-view.ts`、`logic-canvas-styles.ts`（同目录） | 点阵、关系框、外置方形端口、直角流程线、三线引用 |
| 文档、历史与存档 | `packages/web/src/components/canvas-panel.ts` | 按题保存；旧模型保留导出，禁止静默覆盖 |
| 编译到应用协议 | `packages/web/src/canvas/compile.ts`、`canvas/artifact.ts` | 动作及来源表沿用外壳协议；服务端仍权威展开公开方法 |
| 历史兼容测试 | `canvas-panel-legacy-view.ts` 和旧模型辅助模块 | 仅测试历史文档语义，不作为应用画布入口 |

新文档由 `newLogicDocument()` 创建，包含唯一开始节点。外层存档仍为 v2，新增 `document.logic.version = 1` 标记显式连接图；不要把缺少 `logic` 的旧文档按新规则解释。

## 验证方式

按改动范围选择现有检查，注明命令、环境、时间与未执行项。历史通过次数不能替代本次验证。

| 改动 | 检查 |
|---|---|
| TypeScript 或前端组件 | `pnpm typecheck`、`pnpm lint`、相关 Vitest 用例；前端发布前运行 `pnpm build` |
| 画布状态与几何 | `packages/shared/src/canvas/logic-runtime.test.ts`、`packages/web/test/logic-canvas-*.test.ts` |
| 布局、拖动、接线或编辑体验 | 构建后按 [浏览器回归手册](../tests/e2e/README.md) 运行真实后端 E2E |
| VM、API 或安全边界 | 相关单元/集成测试与 [安全验收套件](../tests/acceptance/README.md) |
| 题目包 | `pnpm challenge:check <id>`、`pnpm challenge:solve <id>`，注入对应测试 flag |
| 文档 | 核对代码事实、相对链接与 `git diff --check`，区分历史记录和本次验证 |

CI 命令见 [ci.yml](../.github/workflows/ci.yml)。浏览器真实布局问题不能仅靠 jsdom 或松手后的文档坐标判断。
