## 代码入口

当前画布使用 Lit + HTML 节点 + SVG 连线。画布只显示属性值，编辑统一在侧栏。

| 工作内容 | 主要入口 | 修改时关注 |
|---|---|---|
| 上下布局与页面滚动 | [app-shell.ts](../packages/web/src/components/app-shell.ts)、[canvas-panel.ts](../packages/web/src/components/canvas-panel.ts) | 外层工作区高度、内部三栏布局、控件可达性 |
| 手势、节点渲染、接线 | [canvas-panel-interaction.ts](../packages/web/src/components/canvas-panel-interaction.ts)、[canvas-panel-render.ts](../packages/web/src/components/canvas-panel-render.ts) | 指针坐标、编辑控件焦点、拖拽与点击状态、取消操作 |
| 布局与命中 | [view-model.ts](../packages/web/src/canvas/view-model.ts)、[canvas-panel-geometry.ts](../packages/web/src/components/canvas-panel-geometry.ts) | 盒子与端口坐标来自视图模型，命中用精确盒子而不是锚框 |
| 编辑命令与撤销 | [editor.ts](../packages/web/src/canvas/editor.ts)、[canvas-panel-history.ts](../packages/web/src/components/canvas-panel-history.ts) | 界面只调用命令；一条命令 = 一次可撤销修改 |
| 侧栏属性、工具箱 | [canvas-panel-inspector.ts](../packages/web/src/components/canvas-panel-inspector.ts)、[canvas-panel-toolbox.ts](../packages/web/src/components/canvas-panel-toolbox.ts) | 字段来自节点目录，简单内容就地编辑、复杂配置进侧栏 |
| 分类和节点规格 | [catalog.ts](../packages/web/src/canvas/catalog.ts)、[catalog-specs.ts](../packages/web/src/canvas/catalog-specs.ts) | 18 种节点的默认值、端口与工具箱分组都在这一处 |
| 首次进入与存档 | [save.ts](../packages/web/src/canvas/save.ts)、[canvas-panel.ts](../packages/web/src/components/canvas-panel.ts) | 读不到存档时新建「只有开始节点」的文档；区分无存档、旧档与坏档 |
| 旧档提示与导出 | [archive.ts](../packages/web/src/canvas/archive.ts)、[legacy-archive-bar.ts](../packages/web/src/components/legacy-archive-bar.ts) | 旧档只提示与导出，绝不静默覆盖；只有用户确认才删旧键 |
| 编译与过期状态 | [canvas/compile.ts](../packages/web/src/canvas/compile.ts)、[canvas/artifact.ts](../packages/web/src/canvas/artifact.ts) | 参数变更使产物过期，纯布局修改不改变执行语义 |
| TUI 视觉 | [theme.ts](../packages/web/src/theme.ts)、画布和面板组件 | 复用主题，清晰表达端口、状态和文字层级；`tui-style.test.ts` 会拦渐变、阴影、圆角和内联 HTML |

不要只在界面隐藏默认开始节点：空图的创建、保存、恢复和运行校验必须一致。调整共享初始化函数前，检查它的全部调用者及测试。

## 验证方式

按改动范围选择现有检查，注明命令、环境、时间与未执行项。历史通过次数不能替代本次验证。

| 改动 | 检查 |
|---|---|
| TypeScript 或前端组件 | `pnpm typecheck`、`pnpm lint`、相关 Vitest 用例；前端发布前运行 `pnpm build` |
| 画布状态与几何 | `packages/web/test/graph-*.test.ts` 及相关组件测试 |
| 布局、拖动、接线或编辑体验 | 构建后按 [浏览器回归手册](../tests/e2e/README.md) 运行真实后端 E2E |
| VM、API 或安全边界 | 相关单元/集成测试与 [安全验收套件](../tests/acceptance/README.md) |
| 题目包 | `pnpm challenge:check <id>`、`pnpm challenge:solve <id>`，注入对应测试 flag |
| 文档 | 核对代码事实、相对链接与 `git diff --check`，区分历史记录和本次验证 |

CI 命令见 [ci.yml](../.github/workflows/ci.yml)。浏览器真实布局问题不能仅靠 jsdom 或松手后的文档坐标判断。
