## 代码入口

当前画布使用 Lit + HTML 节点 + SVG 连线。画布只显示属性值，编辑统一在侧栏。

| 工作内容 | 主要入口 | 修改时关注 |
|---|---|---|
| 上下布局与页面滚动 | [app-shell.ts](../packages/web/src/components/app-shell.ts)、[graph-panel.ts](../packages/web/src/components/graph-panel.ts) | 外层工作区高度、内部三栏布局、控件可达性 |
| 手势、节点渲染、接线 | [graph-canvas.ts](../packages/web/src/components/graph-canvas.ts)、[graph-canvas-interaction.ts](../packages/web/src/components/graph-canvas-interaction.ts) | 指针坐标、编辑控件焦点、拖拽与点击状态、取消操作 |
| 画布视图与连线绘制 | [graph-canvas-view.ts](../packages/web/src/components/graph-canvas-view.ts)、[graph-canvas-edges.ts](../packages/web/src/components/graph-canvas-edges.ts)、[graph-canvas-styles.ts](../packages/web/src/components/graph-canvas-styles.ts) | 层级与命中顺序（端口盖住改接把手）、CSS 与 SVG 两套 `transform` 写法 |
| 坐标与折线 | [geometry.ts](../packages/web/src/graph/geometry.ts)、[routing.ts](../packages/web/src/graph/routing.ts)、[port-style.ts](../packages/web/src/graph/port-style.ts) | 屏幕与图坐标转换、缩放中心、端口锚点与正交路由 |
| 编辑命令与撤销 | [editor.ts](../packages/web/src/graph/editor.ts) | 侧栏修改通过编辑命令同步画布；连接替换应是一次可撤销修改 |
| 侧栏属性、节点库 | [graph-panel.ts](../packages/web/src/components/graph-panel.ts)、[node-library.ts](../packages/web/src/components/node-library.ts)、[node-inspector.ts](../packages/web/src/components/node-inspector.ts)、[param-field.ts](../packages/web/src/components/param-field.ts) | 同一份参数状态、复杂配置、预览不触发求值 |
| 分类和节点规格 | [catalog.ts](../packages/shared/src/workflow/catalog.ts)、[catalog-library.ts](../packages/shared/src/workflow/catalog-library.ts)、[catalog-control.ts](../packages/shared/src/workflow/catalog-control.ts)、[catalog-modules.ts](../packages/shared/src/workflow/catalog-modules.ts) | 整理现有节点，保留题目权限和学习阶段约束 |
| 首次进入和空存档 | [schema.ts](../packages/shared/src/workflow/schema.ts) 的 `emptyGraphDocument`、[storage.ts](../packages/web/src/graph/storage.ts)、[graph-panel.ts](../packages/web/src/components/graph-panel.ts) | `emptyGraphDocument` 现在返回空画布；区分无存档、空存档和损坏存档 |
| 编译与过期状态 | [workflow/](../packages/web/src/workflow/)、[artifact.ts](../packages/web/src/workflow/artifact.ts) | 参数变更使产物过期，纯布局修改不改变执行语义 |
| TUI 视觉 | [theme.ts](../packages/web/src/theme.ts)、画布和面板组件 | 复用主题，清晰表达端口、状态和文字层级；`tui-style.test.ts` 会拦渐变、阴影、圆角和内联 HTML |

不要只在界面隐藏默认开始节点：空图的创建、保存、恢复和运行校验必须一致。调整共享初始化函数前，检查它的全部调用者及测试。

## 验证方式

按改动范围选择现有检查，注明命令、环境、时间与未执行项。历史通过次数不能替代本次验证。

| 改动 | 检查 |
|---|---|
| TypeScript 或前端组件 | `pnpm typecheck`、`pnpm lint`、相关 Vitest 用例；前端发布前运行 `pnpm build` |
| 画布状态与几何 | `packages/web/test/graph-*.test.ts` 及相关组件测试 |
| 布局、拖动、接线或编辑体验 | 构建后按 [浏览器回归手册](../tests/e2e/README.md) 运行真实后端 E2E |
| VM、API 或安全边界 | 相关单元/集成测试与 [安全验收套件](../tests/acceptance/README.md) |
| 题目包 | `pnpm challenge:check <id>`、`pnpm challenge:solve <id>`，注入对应测试 flag |
| 文档 | 核对代码事实、相对链接与 `git diff --check`，区分历史记录和本次验证 |

CI 命令见 [ci.yml](../.github/workflows/ci.yml)。浏览器真实布局问题不能仅靠 jsdom 或松手后的文档坐标判断。
