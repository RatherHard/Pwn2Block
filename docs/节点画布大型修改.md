## 流程节点、数据节点、转换节点

画布中明确区分出三类节点：流程节点、数据节点、转换节点

流程节点控制循环、分支的运行，数据节点通过组织数据实现快速搭建 payload ，转换节点作用于数据节点构成的结构上，对数据节点构成的结构的整体值进行类型转换

### 数据节点

数据节点能够快速搭建 payload 的核心是带派生字段变量和 byte 节点吸附拼接

数据节点有这些类型：byte、int、double、string、bool

数据节点之间的连接可以指定运算关系（赋值和逻辑也视作运算）或者拼接关系（构成列表、字符串）

对于 byte/string 节点之间有特殊的吸附拼接作用（可以整体指定分开每个串构成列表还是合并所有串为一个串），可以上下左右拼接，其表示多个串拼接成一个串，拼接顺序为先从左到右后从上到下，注意同一行的串必须要完整连接在一起，且每一行的开头是对齐的

其他类型，也有吸附拼接作用，构成列表，类比同上

列表中的元素可以是不同类型的

在引入带派生字段变量前需要引入全局变量这个概念，全局变量是一种数据节点，可以不初始化；但如果全局变量在初始化的时候使用了其他全局变量参与表达，那么这个全局变量就是带派生字段变量，它后续的值会随参与表达的其他全局变量的改变而改变

全局变量的初始化直接通过赋值的连接进行，毕竟它是数据节点

列表、字符串还有切片功能

bool 节点自带取反功能

还有字典，类比 python 的字典

### 转换节点

把数据节点连成的整体结构或局部结构包络起来，按照指定的方式进行类型转换

转换节点连同被包络的数据节点连成的整体结构或局部结构一同视为一个数据节点

## 流程节点 

包括开始、次数循环、出题人提供的方法

关于数据节点的赋值操作可以视为一个流程节点

其中循环需要包络其他流程结构作为一个整体的流程节点

## UI/交互 重新简洁设计

不要再在节点上放突兀的连接点

首先确定节点都是白色大方框

对于数据节点之间的连接，用一个不同颜色的中小方框表示，这个中小方框同两个数据节点都有一定的间距

流程节点之间的连接线就是正常的非白色直角线，但是连接点飘在节点外部，是小小方框的样式，发出连接线
