# 节点画布大型修改需求

> 历史方案：2026-10-29 起，节点画布 UI 与交互以新的重构要求为准，当前实现见 [02-已实现需求](02-已实现需求.md#节点画布交互与布局)。本文件中端口拖线、就地编辑、预览位置等旧规则不再作为界面验收标准。


状态：需求已完成三轮对齐，尚未实现。确认日期：2026-10-23。

本文件汇总原始需求与已确认的 A–AC 决策，是本次改版的产品需求依据。第三轮 U 经修正：**字典不参与类型转换**。文末保留决策索引，便于追溯确认范围。当前系统行为仍以 [已实现需求](02-已实现需求.md) 为准。

## 1. 改版范围

通过数据节点、流程节点、转换节点搭建 payload 和执行流程。主要能力是数据吸附组合、派生变量、结构化流程，以及对数据结构整体或局部的显式转换。

删除范围限定在旧画布节点体系及配套功能。保留题目加载、后端权威 VM、内存与寄存器观察、调试、提交判题，以及画布保存、撤销等基础能力。后端执行、安全边界和出题 DSL 继续遵守 [基本架构](01-基本架构.md)。

Python 支持整体删除。旧画布能力按第 10 节清单保留、替代或删除，未进入新需求范围的旧画布能力不继续保留。

## 2. 数据节点与值类型

### 2.1 基础类型与集合

| 类型 | 含义 |
| --- | --- |
| `byte` | 字节串，界面使用“字节串”；一个节点承载零个或多个字节，例如 `41 42 00` |
| `int` | 任意精度整数，地址以整数表达 |
| `double` | 64 位浮点数 |
| `string` | 文本，编码为字节串时显式指定编码 |
| `bool` | 真假；节点自带取反功能 |
| 列表 | 可包含不同类型及嵌套集合，保留嵌套层级 |
| 字典 | 键为字符串或整数，值可为任意已支持类型及嵌套集合 |

列表与字典均为可连接、保存的值，不只是视觉分组。字典不参与类型转换，也不提供自动 JSON 或二进制序列化功能；按键取出的值可以按其自身类型转换。此限制不影响字典随工作流存档保存。

字典保留插入顺序。整数键 `1` 与字符串键 `"1"` 不同；重复键报错，不静默覆盖；按键取值时缺失键报错。

### 2.2 吸附与组合

数据节点可以上下左右吸附。组合的成员顺序为先从左到右、再从上到下；每行成员完整相连，各行开头对齐。

每个组合明确选择一种模式：

- **合并为串**：全是字节串时合并为字节串，全是文本时合并为文本。成员必须同类型，字节串与文本不隐式混合。
- **组成列表**：成员各占一个元素，允许混合类型；嵌套列表不自动展开。

创建组合时，全字节串默认合并为字节串，全文本默认合并为文本，其他情况默认组成列表。向已有合并组拖入不兼容类型时提示，不自动改变该组类型。

组合保存明确的行列、成员顺序和模式。普通移动整个组合不改变值，只有吸附、脱离、组内重排或显式修改模式改变结构与结果。折行不插入换行符、分隔符或额外字节。

### 2.3 运算与切片

数据关系表达运算或组合。运算通过关系方框或节点附属操作表达，不继续保留旧式独立运算节点体系。

| 对象 | 首版能力 |
| --- | --- |
| 整数 | 加、减、乘、整除、取余、位运算、移位 |
| 浮点数 | 加、减、乘、除 |
| 数字 | 比较 |
| 布尔 | 与、或、非；与、或短路求值 |
| 列表、文本、字节串 | 长度、按索引取元素、切片、重复 |
| 字典 | 按键取值 |

整数与浮点数混用需要显式转换；条件只接受布尔值。除零、非法移位、索引越界明确报错。

运算关系明确左右操作数，表达式结构决定求值顺序。例如 `a + b × c` 必须明确为 `a + (b × c)` 或 `(a + b) × c`，界面用嵌套结构与表达式预览呈现。节点坐标、连线交叉和关系方框的位置不隐含优先级。

切片使用 `[开始:结束:步长]`：从 `0` 编号，包含开始、不包含结束；允许负索引与负步长，步长不能为 `0`，越界切片边界裁剪。文本按 Unicode 码点、字节串按字节、列表按元素切片，结果保留原类型。

## 3. 全局变量、派生变量与赋值

### 3.1 声明与生命周期

全局变量是一种数据节点。“全局”限定为当前工作流的一次执行，不跨运行保留上次值，不跨题目共享。每次重新执行都从声明的初始状态开始。

每个全局变量有唯一声明，显示名称、固定类型、初值或派生表达式。可创建指向同一声明的引用视图，重命名自动同步。未初始化变量可以存在，实际读取时才报错。

初始化直接通过数据赋值关系表达，关系显示“初始值”或“派生绑定”。

### 3.2 持续绑定与一次赋值

| 关系 | 行为 |
| --- | --- |
| 初始值 | 定义本次执行的初始状态 |
| 派生绑定 | 初始化表达式引用其他全局变量时建立持续绑定；变量只读，每次读取使用该步骤下最新的源变量值 |
| 流程赋值 | 执行到该步骤时取值一次，只写入普通变量 |

例如 `b := a + 1` 表示派生绑定，`b` 跟随 `a` 变化；流程赋值 `c ← a + 1` 只更新该步骤时的 `c`。

初始化依赖按依赖顺序解析，禁止自引用和循环依赖。派生变量标记只读，不能由流程赋值覆盖；改变它需要编辑或解除绑定。解除绑定后成为未初始化的普通变量，不保存上次预览值作为新初值。

流程赋值节点显示“设置变量”，拥有流程入口、出口和数据输入。分支结果与循环累计值通过普通变量和流程赋值实现。

## 4. 转换节点

### 4.1 包络与归属

转换节点包络数据结构的整体或局部，对该结构的整体值进行指定转换；外壳连同内部结构对外视为一个数据节点，提供一个转换结果。

包络是结构容器，不是按坐标判断成员的视觉选框。可以包络完整子表达式或连续组合片段；内部节点归属一个容器，可以嵌套，不能交叉占有。

### 4.2 转换目录

| 转换 | 首版规则 |
| --- | --- |
| 文本 ↔ 字节串 | UTF-8、ASCII；编码明确，非法字符或非法字节严格报错 |
| 整数 ↔ 字节串 | 1/2/4/8 字节、大小端、有符号/无符号；字节串长度必须匹配指定宽度 |
| 整数 → 浮点数 | 不能精确表示时明确报错 |
| 浮点数 → 整数 | 明确选择向零、向下、向上或最近舍入 |
| 数字 ↔ 文本 | 十进制；整数额外支持十六进制 |
| 字节串列表 → 字节串 | 按列表顺序合并 |
| 文本列表 → 文本 | 按列表顺序合并 |

转换参数在节点上显示摘要。无法表示、格式错误、长度不匹配或解码失败均报错，不静默截断或替换字符；不接受 `NaN` 和无穷值。

混合类型列表先对成员显式转换；嵌套列表先处理内层，不递归猜测编码。例如 `[整数, 文本]` 需要先分别转换为字节串，再合并。字典不参与转换，不提供以字典为输入或输出的类型转换。

## 5. 流程节点与执行方式

### 5.1 执行模型

先在工作流求值阶段执行赋值、条件分支和循环，生成动作序列，再交给后端 VM 执行。画布编辑与拖动不会调用出题方法。

出题方法没有依赖 VM 执行结果的数据输出，不采用“VM 方法执行后返回值，再据此计算工作流下一步”的模型。

### 5.2 流程结构

流程节点只有开始、条件分支 `if/else`、次数循环、出题方法和赋值。条件分支与次数循环支持嵌套。

一个工作流有一个开始节点。普通流程节点只有一个后继；条件分支包络“成立/不成立”两个区域，次数循环包络循环体。各区域内部顺序执行，完成后从容器统一出口继续。禁止任意回边及跨容器内部接线。

首版不提供 `while`、`break`、`continue`、自定义流程模块、分支结果节点或循环累计值节点。

### 5.3 次数循环

进入循环时读取一次次数，必须是非负整数，`0` 次合法。循环体修改相关变量，不改变本次循环已经确定的次数。

循环提供从 `0` 开始的只读索引，只在对应循环体及其嵌套区域内可用；嵌套循环可以明确引用外层索引。

### 5.4 出题方法与题目适配

方法节点的名称、参数名与类型来自题目公开声明，数据表达式接入参数。求值执行到该方法时，将当时参数值固定到生成的动作中，后续变量变化不追溯修改已生成动作。

首版沿用现有方法参数类型：字节串、整数、地址。地址在画布上使用整数并校验范围，其他类型先转换后传入。

新画布只展示题目公开声明的方法，移除通用 `feed/write/push/pop/call/ret/step/run` 节点入口。现有题目需要的操作逐题补为公开方法声明，保持原有权限范围。底层 VM 动作继续用于执行，调试面板的步进、运行等能力保留。

## 6. 视觉与结构编辑

### 6.1 节点、关系与编辑位置

- 节点采用白色大方框，不在节点上放突兀的连接点。
- 数据关系采用不同颜色的中小方框，与两个数据节点均留有间距；显示运算符或名称，不能只靠颜色区分。
- 流程连线采用非白色直角线；连接点是节点外部的小方框，由小方框发出连接线。
- 字节串、整数、文本、变量名等简单内容直接在节点内编辑；编码、字节序、切片参数等复杂配置放侧栏。
- 点击关系方框可以切换运算。

从选中数据节点的临时操作入口发起连接，选择目标后出现关系方框；吸附通过拖动完成。一个数据结果可被多处引用，源数据修改同步反映到引用；引用不复制节点、不改变归属。

### 6.2 吸附组编辑

拖动预览明确显示“插入当前行”或“新增一行”，松手后生效。落位后自动压紧并对齐行首，不保留空洞。

移走成员后剩余成员补位，空行消失，相对顺序不变。通过组标题拖动整个组，通过成员拖动调整成员。每次吸附、脱离、重排都是一次可撤销操作。

### 6.3 包络与解除

| 操作 | 行为 |
| --- | --- |
| 包络为转换 | 选中合法数据片段，必须有明确的整体结果 |
| 转换选区被引用 | 若外部引用内部中间结果，先提示处理这些引用；原来引用整体结果的连接改接转换结果，类型不匹配时标错 |
| 包络为循环 | 选中同一区域内连续流程，形成循环体 |
| 创建分支 | 自带两个空区域，再将流程放入 |
| 解除转换 | 保留内部结构 |
| 解除循环 | 展开循环体 |
| 解除分支 | 不提供会含糊合并两条路径的一键解除 |

## 7. 预览、诊断与执行产物

编辑时仅预览纯数据表达式。依赖流程赋值或循环索引的值显示“待执行”，不以上次执行值冒充当前值。生成动作序列后，可以按步骤和循环轮次查看当时的值。

结构错误与类型错误阻止生成。未初始化读取等求值错误只在实际执行路径读到时触发；未执行分支或布尔短路跳过的求值不额外触发这类错误。

生成失败不发布部分动作，旧产物标记过期。保留执行预算，并限制集合与重复操作的结果大小。

## 8. 存档与兼容

新画布使用新的存档版本，首版不自动迁移旧图。检测到旧存档时明确提示不兼容，允许导出旧文件，由用户主动创建新版画布；不静默清空或覆盖旧存档。

## 9. Python 删除范围

删除 Python 节点、编辑器、求值 API、运行器、部署配置及相关入口，清理相应共享协议、调用方、专属测试和当前使用文档。有效的非 Python 画布能力仍需保留并适配其测试。

Python 专属能力不以隐藏入口或不可用选项的形式留在新产品中。

## 11. 验收场景

以下是实现后的验收要求，本次需求对齐未执行这些产品测试。

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| AT-01 | 字节串 `41`、`42` 放第一行，`43` 放第二行；整组移动、组内重排 | 初始结果 `414243`；整组移动不改变结果，重排按成员顺序改变结果；折行不加字节 |
| AT-02 | 将全字节串组合切换为列表；尝试把文本拖进既有字节串合并组 | 列表保留各成员；不兼容拖入明确提示，不自动切换类型 |
| AT-03 | 构造混合列表和嵌套列表 | 类型与层级保持；整体转字节串前必须逐项处理，不隐式展开或编码 |
| AT-04 | 字典同时使用整数键 `1` 和字符串键 `"1"`；重复键、缺失键、对字典转换 | 两个键独立并保留顺序；重复和缺失报错；字典没有转换入口，非法转换不能执行；取出的值可按自身类型转换 |
| AT-05 | `a` 初值为 `1`，派生 `b := a + 1`；依次执行 `c ← a + 1`、`a ← 4` | 后续读取 `b` 为 `5`、`c` 为 `2`；重新执行从初态开始 |
| AT-06 | 写入派生变量、解除绑定、制造变量自引用或循环依赖 | 写入被阻止；解除后未初始化；自引用与循环依赖明确报错 |
| AT-07 | 方法取用派生 payload 后再修改源变量 | 已生成动作的参数不变化；后续方法使用更新后的值 |
| AT-08 | 以变量值 `3` 进入循环，循环体改变该变量；嵌套访问外层索引 | 本次仍执行三次，索引为 `0/1/2`；外层索引明确可选，越出所属作用域不能使用 |
| AT-09 | 零次、负数、非整数次数；在分支、循环之间跨区域接线或创建回边 | 零次跳过循环体；其余非法次数与非法连线明确报错或阻止 |
| AT-10 | 构造两种嵌套表达式；整数和浮点数混用；布尔短路右侧包含未初始化读取 | 求值遵循结构；混用要求显式转换；短路跳过的读取不触发求值错误 |
| AT-11 | 对文本 `A😀B`、字节串和列表做切片，使用负步长、越界边界和零步长 | 文本按码点；类型保持；边界裁剪；零步长报错，单元素索引越界报错 |
