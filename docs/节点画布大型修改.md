## 流程节点、数据节点、转换节点

画布中明确区分出三类节点：流程节点、数据节点、转换节点

流程节点控制循环、分支的运行，数据节点通过组织数据实现快速搭建 payload ，转换节点作用于数据节点构成的结构上，对数据节点构成的结构的整体值进行类型转换

### 数据节点

数据节点能够快速搭建 payload 的核心是带派生字段变量和 byte 节点吸附拼接

数据节点有这些类型：byte、int、double、string、bool

数据节点之间的连接可以指定运算关系（赋值和逻辑也视作运算）或者拼接关系（构成列表、字符串）

对于 byte/string 节点之间有特殊的吸附拼接作用（可以整体指定分开每个串构成列表还是合并所有串为一个串），可以上下左右拼接，其表示多个串拼接成一个串，拼接顺序为先从左到右后从上到下，注意同一行的串必须要完整连接在一起，且每一行的开头是对齐的

其他类型，也有吸附拼接作用，构成列表，类比同上

列表中的元素可以是不同类型的

在引入带派生字段变量前需要引入全局变量这个概念，全局变量是一种数据节点，可以不初始化；但如果全局变量在初始化的时候使用了其他全局变量参与表达，那么这个全局变量就是带派生字段变量，它后续的值会随参与表达的其他全局变量的改变而改变

全局变量的初始化直接通过赋值的连接进行，毕竟它是数据节点

列表、字符串还有切片功能

bool 节点自带取反功能

还有字典，类比 python 的字典

### 转换节点

把数据节点连成的整体结构或局部结构包络起来，按照指定的方式进行类型转换

转换节点连同被包络的数据节点连成的整体结构或局部结构一同视为一个数据节点

## 流程节点 

包括开始、次数循环、出题人提供的方法

关于数据节点的赋值操作可以视为一个流程节点

其中循环需要包络其他流程结构作为一个整体的流程节点

## 需求对齐记录

本节记录已确认的产品决策，作为上文原始需求的补充和歧义澄清。这里描述的是目标行为，不代表当前实现已经具备这些能力。未确认的细节继续按依赖关系分轮审查，每轮同时审查互不依赖的决策。

### 第一轮：A–I（2026-10-23 已全部确认）

#### A. 删除范围

“上述以外的已有多余部分/功能全部砍掉”限定在旧画布的节点体系及配套功能。保留题目加载、后端 VM、内存/寄存器观察、调试、提交判题，以及画布保存、撤销等基础能力。旧画布能力按新需求重新列保留清单，未进入清单的删除。

Python 支持按原始需求删除。具体旧节点替代关系和删除清单仍需后续确认。

#### B. byte 表示字节串

`byte` 定义为字节串，一个节点可承载零个或多个字节，例如 `41 42 00`；界面名称使用“字节串”。

#### C. 值类型

- `int` 使用任意精度整数，避免地址丢失精度。
- `double` 使用 64 位浮点数。
- `string` 表示文本，编码成字节时显式指定编码。
- `bool` 只接受真假。
- 列表和字典是可以参与连接、保存和转换的值，不只是视觉分组。

#### D. 拖动与数据语义

吸附形成的组合保存明确的行列和成员顺序。普通移动整个组合不改变值；只有明确吸附、脱离或组内重排才改变结构和结果。拖拽预览显示插入位置，松手后生效。

#### E. 全局变量的生命周期

“全局”限定为当前工作流的一次执行。每次重新执行都从声明的初始状态开始，不跨运行保留上次值，不跨题目共享。未初始化变量可以存在，但被实际读取时明确报错。

#### F. 求值与执行时机

保留先求值生成动作序列、再交给后端 VM 执行的整体方式。工作流求值期间执行赋值、循环等逻辑。画布可以预览纯数据表达式，但编辑、拖动不会调用出题方法。

本轮不采用“方法在 VM 执行后返回结果，再据此计算工作流下一步”的执行模型。

#### G. 流程控制范围

流程节点包括开始、条件分支 `if/else`、次数循环、出题人提供的方法和赋值。条件分支与次数循环支持嵌套。首版删除 `while`、`break`、`continue` 和自定义流程模块。

#### H. 转换包络的归属

转换包络是明确的结构容器。选中完整子表达式或连续的组合片段后包络，容器有一个转换结果。内部节点归属一个容器，可以嵌套，不能被两个包络交叉占有。框的位置和大小本身不决定成员。

#### I. 编辑位置

简单内容直接在节点内编辑，例如字节串、整数、文本、变量名。复杂配置放侧栏，例如编码、字节序、切片参数。彩色关系方框可以点击切换运算，并显示运算符或名称，不能只靠颜色区分。

### 第二轮：J–T（2026-10-23 已全部确认）

#### J. 吸附组合模式

每个组合明确选择“合并为串”或“组成列表”。全是字节串时默认合并为字节串，全是文本时默认合并为文本，其他情况默认组成列表。合并模式要求成员类型一致，字节串和文本不能隐式混合。

往已有合并组拖入不兼容类型时提示，不自动改变该组类型。嵌套列表保留层级，不自动展开。

#### K. 字典

首版支持字符串和整数作为键，值支持任意已支持类型及嵌套集合。保留插入顺序；整数键 `1` 与字符串键 `"1"` 不同；重复键报错，不静默覆盖。提供按键取值，缺失键报错。

#### L. 派生变量与流程赋值

初始化表达式引用其他全局变量，就建立持续绑定，该变量只读；想改变它，需要编辑或解除绑定。流程中的赋值是执行到该步时取值一次，只写入普通变量。

例如，派生变量 `b := a + 1` 跟随 `a`；流程赋值 `c ← a + 1` 只更新当时的 `c`。初始化依赖按依赖顺序解析，禁止自引用和循环依赖；后续每次读取派生变量，都使用该步骤下最新的源变量值。

#### M. 表达式的运算顺序

运算关系必须明确左右操作数，表达式结构决定求值顺序。搭建 `a + b × c` 时，要明确选择 `a + (b × c)` 或 `(a + b) × c`，界面用嵌套结构及表达式预览呈现。

节点坐标、连线交叉、关系方框的位置都不隐含运算优先级。

#### N. 流程连接与容器边界

一个工作流有一个开始节点。普通流程节点只有一个后继；条件分支包络“成立/不成立”两个区域，次数循环包络循环体。各区域内部顺序执行，完成后统一从容器出口继续。

禁止任意回边及跨容器内部接线，循环通过循环容器表达。

#### O. 循环次数与索引

进入循环时读取一次次数，必须是非负整数，`0` 次合法。循环体改变相关变量，不改变本次循环已经确定的次数。

提供从 `0` 开始的只读索引，只在对应循环体及其嵌套区域内可用；嵌套循环可以明确引用外层索引。

#### P. 出题方法的参数与输出

方法节点由题目公开声明提供名称、参数名和类型，数据表达式接入参数。工作流求值到该方法时，将当时的参数值固定到生成的动作中，后续变量变化不追溯修改已生成动作。

方法节点不提供依赖 VM 执行结果的数据输出。

#### Q. 基础类型转换

首版提供文本与字节串互转、整数与字节串互转、整数与浮点数互转、数字与文本互转。

整数与字节串转换明确宽度、字节序、有无符号；浮点数转整数明确舍入方式。无法表示、格式错误或解码失败均报错，不静默截断或替换字符。

集合如何整体转换仍待后续确认。

#### R. 切片

列表、文本、字节串均支持 `[开始:结束:步长]`：从 `0` 编号，包含开始但不包含结束，允许负索引与负步长，步长不能为 `0`，越界边界裁剪。

文本按 Unicode 码点切片，字节串按字节，列表按元素；结果保留原类型。

#### S. 数据关系的创建和复用

从选中数据节点的临时操作入口发起连接，选择目标后出现关系方框；吸附通过拖动完成。

一个数据结果可以被多处引用，修改源数据后各引用同步反映。引用不复制节点，也不改变节点归属。流程连接继续使用外置小方框。

#### T. 旧存档

新画布使用新的存档版本，首版不做旧图自动迁移。检测到旧存档时明确提示不兼容，允许导出旧文件，并由用户主动创建新版画布；不静默清空或覆盖旧存档。
