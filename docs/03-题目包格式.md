# 03 题目包格式

每道题对应一个目录 `challenges/<id>/`，内含两个文件：

- `public.json`：公开包，可以原样下发给浏览器。
- `private.json`：私有包，只由服务端读取，永不下发。

两个包都用 JSON Schema 校验，服务端加载时校验，失败即拒绝加载。MVP 不做题目包的编译、签名、哈希和发布链路。

**设计原则**：完整内存布局只写在私有包里。前端看到的初始状态由服务端从私有包实时投影得到（见 [04](04-会话与API.md) §4），因此出题人不需要手工维护一份“公开初始投影”，也就不存在两份数据不一致的问题。

## 1. 公开包 `public.json`

| 字段 | 说明 |
|---|---|
| `id` / `title` | 题目标识与标题 |
| `briefing` | 题面（Markdown） |
| `archBits` | 32 或 64 |
| `encoding` | 指令编码表，见 [02](02-VM模块.md) §4 |
| `labels` | 语义标注 `[{ name, addr, size, kind }]`，`kind ∈ func / buffer / saved_bp / ret_addr / custom`。`func` 用于指令视图的函数列表，其余用于栈视图高亮 |
| `allowedActions` | 本题允许的动作子集，见 04 §2 |
| `authorBlocks` | 出题人积木，见 §3 |
| `hints` | 提示阶梯 `[{ text, unlockAfterFailures? }]`。默认按请求逐级揭示；设置了 `unlockAfterFailures` 的条目，在失败达到该次数后自动揭示 |
| `errorNotes` | `{ <errorCode>: 教学文案 }`，覆盖默认的错误解释 |

## 2. 私有包 `private.json`

| 字段 | 说明 |
|---|---|
| `registers` / `roles` / `secretRegisters` | 见 02 §2 |
| `initRegisters` | 初始寄存器值；未列出的寄存器为 0 |
| `vmas` | VMA 列表，见 02 §3，包括隐藏 VMA |
| `interfaces` | syscall 接口，见 02 §5 |
| `win` | 成功条件（谓词树），必填 |
| `fail` | 失败条件列表（可选）。失败优先于成功 |

### 2.1 判题谓词

| 谓词 | 参数 |
|---|---|
| `reg_eq` | `reg`, `value` |
| `mem_eq` | `addr`, `hex` |
| `mem_contains` | `vma`, `hex`（不超过 64 字节） |
| `exited` | `code?` |

- 谓词可以用 `all / any / not` 组合，最多嵌套 3 层。
- 每个执行类动作结束后求值一次，失败条件先于成功条件求值。
- 公开面只返回 `won / failed`，不返回部分匹配的进度。

MVP 不提供 `ret_target_equals`、`stack_canary_intact`、隐藏测试和多阶段状态机，需要时可以用 `mem_eq` 或 `reg_eq` 表达。

## 3. 出题人积木 `authorBlocks`

出题人积木是出题人提供的“交互接口”，以积木的形式出现在工具箱里。它的本质是一个**服务端展开的动作模板**：

```json
{ "id": "gets", "label": "gets(buf)", "tooltip": "向 buf 写入任意长度字节（不检查边界）",
  "params": [ { "name": "data", "type": "bytes" } ],
  "expand": [ { "type": "write_bytes", "addr": "0x7fffefe0", "hex": "$data" } ] }
```

- `params.type` 取值为 `bytes / int / addr`。
- `expand` 是参数化的原子动作列表，只能引用参数，没有控制流。
- 前端只发送 `{ type: "block", id, args }`，**展开动作由服务端完成**，客户端提交的展开结果一律不被信任。
- 出题人积木的展开动作不受 `allowedActions` 限制，这是它存在的意义。比如可以禁用裸 `write_bytes`，只允许通过 `gets` 溢出。

## 4. 示例：ret2win（64 位）

这道题的场景是：`vuln` 已经执行完 `gets(buf)` 前的序言，当前停在 `leave`。原返回地址指向 `lose`。

`public.json`（节选）：

```json
{
  "id": "ret2win", "title": "回到胜利", "archBits": 64,
  "briefing": "让程序返回到 win（0x400002）。",
  "encoding": [
    { "opcode": "0xc9", "op": "leave",   "operands": [] },
    { "opcode": "0xc3", "op": "ret",     "operands": [] },
    { "opcode": "0x0e", "op": "syscall", "operands": ["const:0"], "mnemonic": "syscall exit" },
    { "opcode": "0x0f", "op": "syscall", "operands": ["const:1"], "mnemonic": "syscall win" }
  ],
  "labels": [
    { "name": "buf",      "addr": "0x7fffff00", "size": 16, "kind": "buffer" },
    { "name": "saved rbp", "addr": "0x7fffff10", "size": 8, "kind": "saved_bp" },
    { "name": "ret addr", "addr": "0x7fffff18", "size": 8, "kind": "ret_addr" }
  ],
  "allowedActions": ["step", "run", "undo", "reset"],
  "authorBlocks": [
    { "id": "gets", "label": "gets(buf)", "tooltip": "从 buf 起写入字节，不检查长度",
      "params": [ { "name": "data", "type": "bytes" } ],
      "expand": [ { "type": "write_bytes", "addr": "0x7fffff00", "hex": "$data" } ] }
  ],
  "hints": [
    { "text": "观察 RBP 与 ret addr 的位置关系。" },
    { "text": "buf 到 ret addr 的距离是多少字节？" },
    { "text": "地址按小端序写入。", "unlockAfterFailures": 3 }
  ]
}
```

`private.json`：

```json
{
  "registers": ["RAX", "RSP", "RBP", "RIP", "FLAG"],
  "roles": { "sp": "RSP", "bp": "RBP", "ip": "RIP" },
  "secretRegisters": ["FLAG"],
  "initRegisters": { "RSP": "0x7fffff00", "RBP": "0x7fffff10", "RIP": "0x400000" },
  "vmas": [
    { "id": "text",  "kind": "code",  "start": "0x400000",   "size": "0x1000", "perm": "rx",
      "init": [ { "at": "0x400000", "hex": "c9c30f0e" } ] },
    { "id": "stack", "kind": "stack", "start": "0x7fffe000", "size": "0x2000", "perm": "rw",
      "init": [ { "at": "0x7fffff10", "hex": "40ffff7f000000000300400000000000" } ] }
  ],
  "interfaces": [
    { "id": 0, "name": "exit", "effects": [ { "type": "exit" } ] },
    { "id": 1, "name": "win",  "effects": [ { "type": "set_flag", "reg": "FLAG", "value": "0x1" }, { "type": "exit" } ] }
  ],
  "win":  { "reg_eq": { "reg": "FLAG", "value": "0x1" } },
  "fail": [ { "all": [ { "exited": {} }, { "not": { "reg_eq": { "reg": "FLAG", "value": "0x1" } } } ] } ]
}
```

参考解法：调用 `gets`，参数为 `"A"×16 + "B"×8 + p64(0x400002)`，然后 `step` 三次（`leave`、`ret`、`syscall win`），会话进入 `won`。
