# 10 前端美术与页面设计任务书

> 给新 AI 的独立任务：完成 Pwn2Block 页面视觉与交互原型，供前端 D / 积木 H 接入。
> 整理日期：2026-10-15。来源为 [08-Agent并行开发日程](08-Agent并行开发日程.md) 的 D01–D03、H01–H02，以及 [05-前端交互](05-前端交互.md)。
> 本文把已有要求拆成设计交付；“设计建议”是补充内容，不代表新增产品功能。原型完成不等于真实 API 联调或 G3 验收。

## 1. 任务目标与产品背景

Pwn2Block 面向 Pwn 初学者：学习者阅读题面，观察栈、寄存器和指令，用积木构造 payload，在调试实例中试验，再提交到独立判题实例从初态回放。

请产出可打开、可切换关键状态的高保真原型和可实施的视觉规范，让地址、字节、指令与操作关系清晰，帮助初学者判断当前内容和下一步操作。

设计只覆盖做题工作台及其状态，不扩展官网、登录注册、排行榜、课程商城、个人中心或出题后台。前端不执行 VM、不推导判胜、不读取私有题目数据。

## 3. 必须保留的页面结构

- 单页工作台，顶部为“视图”“运行”两组菜单及“调试模式 / 判题结果”切换。
- 可折叠题面面板，显示题面与分级提示。
- 主工作区左右 **1:1**，两半之间无间隙、无边框；左边是视图管理器，右边是 payload 窗口。
- 左侧同时显示两个视图槽位，上下排列，其余视图通过纵向平滑滚动切换。视图列表支持显示/隐藏与拖动排序，`Ctrl+↑ / Ctrl+↓` 切换视图。
- 右侧按上下顺序排列：Blockly 画布及工具栏、程序区、输出区。
- 调试和判题结果复用同一套内存视图，清楚标识当前数据源。回放时间线只属于判题结果模式。

结构示意（面板内部的尺寸由设计确定）：

```text
┌───────────────────────────────────────────────────────────┐
│ Pwn2Block / 题目名称    视图   运行    调试模式 | 判题结果   │
│ 题面与分级提示（可折叠）                                   │
├─────────────────────────────┬─────────────────────────────┤
│ 视图管理器                  │ Payload 工具栏              │
│                             │ Blockly 工具箱 + 积木画布   │
│ 上方视图槽                  │                             │
│                             │                             │
│ 下方视图槽                  │ 程序区：编译后的动作序列    │
│                             │ 输出区：结果与错误解释      │
└─────────────────────────────┴─────────────────────────────┘
```

示意图中央竖线只表示区域划分，正式页面不绘制分隔边框。判题结论和时间线只在结果模式出现，位置由原型确定，但要保留内存与程序阅读空间。

## 4. 视觉方向与设计自由度

### 已定要求

- 只做一套深色终端风格，使用等宽字体；界面文案中文，寄存器、地址、指令及 API 标识保留技术名称。
- 面向桌面浏览器，不增加移动端产品流程。
- 地址、hex、ASCII 与伪汇编对齐显示，变化高亮一次；状态不能只靠颜色表达，必须同时有文字或符号。
- 不提供主题切换、可配置视图模板、可调整的左右分屏比例、自定义列或断点开关。

### 设计建议（可细化）

- 以清晰、紧凑的调试器为方向，用低对比背景区分区域，把强调色留给当前操作、指令、变化字节和判题结论。
- 可沿用深灰绿背景、绿色主强调、黄色变化、红色错误、紫色隐藏标签和蓝色焦点，并调整色值保证可读性。
- 提供颜色、字体、字号、行高、间距、圆角、控件高度、表格密度、焦点和动效 token 表，并标明用途。
- 以 1440×900 为主稿，并在 1280×720、1920×1080 检查布局；小桌面可增加内部滚动、压缩留白，但保持 1:1 和关键操作可达。
- 图标采用一致的轻量线性风格，关键操作带中文标签；不使用插画或背景图，避免占用调试空间。
- 说明长地址、错误、题面和动作列表的溢出规则。动效只用于定位与变化识别，不做持续闪烁或装饰性动画。

## 5. 各区域的设计要求

### 5.1 顶栏、题面与提示

顶栏清楚显示题目名称、当前模式及两组菜单。“运行”菜单与 payload 工具栏行为一致。题面展开和折叠都需要完整状态，折叠后仍能识别当前题目。

提示按顺序揭示，提供“下一条提示”。达到 `unlockAfterFailures` 阈值时自动揭示并通知；已揭示提示按题目 id 本地保存。画出未揭示、已揭示、自动揭示、全部揭示四种状态，不设计扣分或剩余提交次数。

### 5.2 左侧视图

| 视图 | 必须画出的信息与交互 |
|---|---|
| 栈 | 每行 W 字节，64 位示例为 8 字节；地址、字节、值与 ASCII；对齐偏移、地址跳转、hex/ASCII 搜索；`sp`/`bp` 锚点；`buffer / saved_bp / ret_addr / custom` 类别标签；执行后跟随 `sp` |
| 指令 | 地址、机器码、伪汇编三列；当前 `ip` 高亮并跟随；可点击的跳转/调用目标；从 `func` 标签生成函数列表；行首无断点按钮 |
| 寄存器 | 所有公开寄存器和 `ZF / CF / SF`；变化提示、点击复制及复制反馈；其他视图中的寄存器地址标签 |
| 自由内存 | VMA 列表：id、kind、label、范围、权限；选择可见 VMA 后显示 hex dump；隐藏 VMA 仅显示布局与“隐藏”标记 |
| I/O | 仅题目声明 `syscalls` 或 `fds` 时出现；stdout 的 ASCII/hex 切换与新增高亮；stdin 已读部分置灰；公开的 syscall ABI、调用号、名称、说明及 fd 速查 |

栈的指针链最多 3 跳，只跳到公开可见内容；到可执行区域时显示投影提供的伪汇编。隐藏字节显示 `??` 并标出 VMA，未映射位置为空，不能混为同一种状态。前端不解码指令，也不提供任意地址读取。

样稿至少展示一次 buffer、saved_bp、ret_addr 的相邻关系，一次值变化，以及一次可见/隐藏/未映射内容的区别。32/64 位与寄存器名由题目决定，不把 RSP/RBP 等示例名称写成全产品固定配置。

### 5.3 Blockly 画布

- 工具箱展示“通用”“字节”“动作”“出题人积木”四类；分类色与成功、错误等状态色能区分。
- 字节类覆盖 `padding / string / int / addr / raw / concat`，动作类按题目 `allowedActions` 过滤，出题人积木从公开声明生成。
- 画出唯一“开始”积木、已连接积木、未连接积木、选中、悬停 tooltip、参数错误与编译错误高亮。
- 未连接到开始块的积木不参与编译；画布需能解释这一点。`feed` 的 tooltip 说明必须放在触发读取的 `step / run` 之前。
- 本轮不展示列表、带返回值的函数或“读取当前寄存器/内存”积木；变量与表达式只在编译期求值。
- 原型可用静态积木外观表达布局，但须标明哪些拖拽、编译行为是模拟的。交接时给出对应真实 Blockly 的样式约束，不能用图片冒充可用编辑器。

### 5.4 工具栏与程序区

| 操作 | 必须保持的语义 |
|---|---|
| 编译 | 本地把积木变成动作序列，不发送执行请求 |
| 试运行 | 在调试实例执行程序区剩余动作；用完后提交 `run` |
| 单步 | 执行下一个 payload 动作；用完后提交 VM `step` |
| 运行 N 步 | 数字输入与按钮，提交带 `count` 的 `step` |
| 后退一步 | 调试实例回退一条指令，最近 64 条内有效 |
| 撤销 | 调试实例回退上一次请求 |
| 重置 | 调试实例回到初态，程序区执行位置回到开头 |
| 提交判题 | 提交完整 payload，由独立判题实例从初态回放 |

“提交判题”应与调试操作有明确视觉层级。没有暂停按钮；请求期间展示等待状态，串行发送请求，避免重复触发。无可退历史时禁用回退按钮并提供原因。

程序区展示行号、原子动作和当前位置。设计未编译、编译成功、编译失败、产物过期、执行中、已执行完六种状态。修改积木后必须显示“已过期，请重新编译”，禁止用旧产物试运行或提交。错误行能够关联到出错积木；编译限制错误也必须有可定位的解释。

### 5.5 输出、判题与回放

输出区区分动作成功、动作被拒、运行异常、编译错误。错误展示 `error.message` 与 `error.note`；有公开可见的出错地址时可定位到相应视图，缺少详细字段时不编造原因。

| 状态 | 页面应表达的内容 |
|---|---|
| 调试 `satisfied` | “当前状态已满足成功条件”，引导提交判题；不显示 flag 或判胜依据，仍可继续调试 |
| 调试 `failed / exited` | 原因与后退一步、撤销、重置入口，遵循各按钮可用状态 |
| 判题 `won` | 通过横幅、flag、复制按钮与复制反馈，提示去 CTF 平台提交 |
| 判题 `incomplete` | “payload 跑完了，但没有达成目标”，给出回放与返回调试入口 |
| 判题 `failed` | 异常或失败说明，默认定位失败帧 |
| 判题 `rejected` | 被拒动作及原因，高亮对应程序行与积木 |

四种判题结果都提供回放时间线，拖动后所有视图同步切到选中帧。说明帧位置与动作位置的关系，不把逐动作回放表现成逐指令录像。始终可“回到调试”，返回的是提交前保留的调试状态；结果模式不能暗示正在实时操作调试实例。

### 5.6 加载、恢复与可访问性

补齐首次加载、无可用题目、请求等待、网络错误、会话失效及重新开始状态。按 05 §6 提供会话失效提示和“重新开始”入口；刷新恢复已有会话时读取当前服务端状态，不承诺保存 payload、成绩或完整调试历史。

所有按钮与菜单支持键盘操作且有可见焦点；状态播报使用 `aria-live`；屏幕阅读器可识别当前模式。设计禁用原因、复制反馈与文本状态标签。Blockly 完整键盘导航属 P1，不把它写成此次已实现能力。

## 6. 新 AI 的工作边界

仓库已有页面骨架、主题、公开样例、viewmodel、blocks 和 compiler（见 `packages/web/src/`）。08 开头“尚无可运行代码”是早期描述，实际起点以当前代码和文末交接记录为准。

设计默认独立输出到 `design/frontend/`，与 D/H 生产代码分开；沿用 08 的单文件单写入者规则，由 A 统一集成。若后续直接接入，仍按 D/H 的写入边界分配。

- 可以：制作 HTML/CSS/少量 JS 的可交互原型、设计 token、状态样例、截图和交接说明。
- 原型数据只用合成的公开样例或现有公开 fixture；演示 flag 使用显眼的“示例，非真实 flag”文字。
- 不修改 `packages/shared/**`、服务端、引擎、根配置或锁文件；不替 D/H 重写编译器与业务状态。
- 不读取 `private.json`、环境变量或参考解法来生成页面展示内容。原型按钮仅切换预设样例，不在浏览器模拟真实 VM 或推算判胜。
- 数据不足时记录“契约缺口”：所需展示信息、现有字段、影响状态及建议接收方。特别核对 `sp/bp/ip` 的 roles 来源，不把样例兜底当作生产接口。
- 本轮只使用独立原型所需的本地资源，不增加项目依赖。产物应能迁移到现有 Vite + Lit + Blockly 页面。

## 7. 必交产物与验收方式

建议采用以下交付结构；这些文件由新 AI 创建，当前不一定已存在：

```text
design/frontend/
  README.md             # 打开方式、页面状态目录、已做/未做、模拟行为
  index.html            # 可直接打开的高保真工作台原型
  styles.css            # token 与布局/组件样式
  prototype.js          # 预设状态切换、菜单、折叠、回放等演示交互
  design-spec.md        # 视觉规范、组件状态、尺寸、滚动与溢出规则
  handoff.md            # D/H 接入映射、公开数据需求、契约缺口
  screenshots/          # 关键状态截图及尺寸标记
```

原型必须能演示：模式切换、题面折叠、视图显示/隐藏与排序、提示展开、编译结果过期、错误定位、四种判题结果、时间线切换和返回调试。用于选择样例状态的控件应明确标成“原型演示”，在交接中说明不进入产品。

最低截图集：默认调试工作台、I/O 与隐藏内存、编译过期、错误定位、调试满足条件、四种判题结果、会话失效。可用同一工作台切换状态，不需为每种状态制作独立路由。

交接说明按组件列出：对应的现有文件、输入展示数据、用户操作、普通/悬停/焦点/禁用/等待/错误状态、D 或 H 的接入责任。避免为了视觉方案要求改 API。

- [ ] 默认工作台保留左右 1:1、两个可见视图槽与右侧三个区域。
- [ ] 四种内存视图与条件 I/O 均有设计；地址、字节、伪汇编和指针链可读。
- [ ] 工具栏语义、产物过期、回退限制与请求等待有明确表现。
- [ ] 调试满足条件与正式判题通过能一眼区分，只有后者显示示例 flag。
- [ ] 四种 verdict、回放和返回调试均可演示，样例状态切换不会覆盖演示的调试状态。
- [ ] 覆盖加载、空态、错误、恢复、长文本与小桌面尺寸；关键按钮不被遮挡。
- [ ] 键盘焦点、非颜色状态提示、模式识别与播报位置已标注。
- [ ] 实际打开原型检查交互，记录浏览器、尺寸和结果；未经验证的能力标为未验证。
- [ ] 文件清单、预览方式、截图、token 和 D/H 接入说明齐全。

这些勾选只验证设计产物；08 的 G3 仍要求真实服务、真实首题和 Playwright 八步闭环，不能因原型完成提前勾选。
