# 数据连接结构交互方案

状态：**待审核，尚未实现**。日期：2026-10-31。

目标：保持现有横向数据节点、运算/赋值关系框、虚线包络、结果摘要与附件的呈现形式，重新定义快捷拖拽、插拔、尾端整体移动和包络归属。以下是供审核的建议行为，不代表当前软件已经具备。

## 1. 审核摘要

建议用两个已有对象承担不同手势：**拖节点搬结构，拖关系框拔尾段**。

| 操作 | 建议结果 |
| --- | --- |
| 拖整体最右端的数据节点 | 整条数据结构移动，内部关系、嵌套包络和附件全部跟随 |
| 拖包络内最右端的数据节点 | 把该包络视为整体移动；若它还与外部数据结构连接，外部结构一并跟随，具体边界见第 3 节 |
| 拖其他数据节点或包络标题 | 同样移动其完整结构；无需寻找专用把手 |
| 拖两个节点之间的关系框 | 从该处断开，带走右侧整段，左侧留在原处 |
| 将一个节点或整段拖近空闲端点 | 预览后吸附接续，一次松手完成 |
| 将一个节点或整段拖到已有关系框 | 预览插入位置，松手后插入，原右侧整段让位 |
| 选中关系框后按 Delete | 只移除这条连接，保留两侧节点；若在包络内，右侧整段自动移出 |
| 对一个结构执行包络 | 只包一个连通整体；多个互不连接的结构不能放进同一包络 |
| Esc / 撤销 | Esc 放弃本次拖动；一次撤销恢复本次全部连接、成员归属、位置和图层 |

主要类比是直接拖入、吸附预览、一次拔起一段和一次操作一次撤销。保留当前横向表达式形式，不把节点改成积木形状，也不增加常驻端口或拖动把手。

## 2. 结构与方向的定义

**同层结构**：同一个直属包络中，或画布顶层中，由数据关系连接起来的一条连续横向结构。一个独立数据节点也算一个结构。嵌套包络在父层按一个节点参与连接；其内部另算一层。

**尾端**：当前层级最右侧没有后继的数据节点或子包络。以连接定义的左右次序判断，不按鼠标位置、数组顺序或全画布最大 x 坐标猜测。赋值始终按画面上的 `变量 ← 表达式` 判断左右，不能直接把边的 `from/to` 当作左右。

**右侧尾段**：从某条关系框的右端开始，到该层尾端为止的全部节点、内部关系、嵌套包络及其附件。它不包含刚被移除的关系框。

```text
A ─ + ─ B ─ × ─ C ─ + ─ D
                          ↑ 尾端
        拔开 × ：左段 A + B；右侧尾段 C + D

A ─ + ─ E[ B ─ × ─ C ] ─ + ─ D
                    ↑ E 内尾端   ↑ 外层尾端
```

流程线和引用线不把两个数据结构合并为拖动整体。它们可以连接移动与静止的对象，移动时更新端点；不拖走被引用的方法、条件分支等对象。附着在移动包络上的转换或循环随宿主移动。

## 3. 整体移动与尾端

### 3.1 默认手势

按住节点本体或包络标题移动，拖动开始时计算一次移动集合，之后保持不变。最右侧尾端是可直接使用的整体提手，其他节点本体也采用相同规则。

建议移动集合按以下方式闭合：先取得命中节点所在的同层数据结构；若它属于包络，包含这个包络及其所有内部成员；继续纳入该包络在父层通过数据关系相连的结构，直至没有包络归属和数据连接需要追加。附件随宿主加入。这样的移动不拔掉任何已有数据关系。

例如 `A + E[B × C] + D`，拖 D、拖 C 或拖 E 标题都会移动这个完整整体。拖动前高亮实际会移动的范围，避免用户以为只会移动 C。

这是本稿明确提出的设计选择：**包络内尾端可以提起包络，但不会隐式拔掉包络的外部连接。** 若希望只取出 E 或它内部的一段，先在目标关系处拔开；取出整个包络内容使用现有“解除包络”操作。该选择仍待本轮审核。

### 3.2 选择、微调和防误操作

- 单击保持选择/编辑；超过建议的 5 个屏幕像素才启动拖动。距离按屏幕像素判断，使不同缩放下手感一致。
- 节点本体拖动时扩展到完整移动集合；Shift 多选及框选仍用于选择。多选后移动时，对每个选择计算移动集合，再去重。
- 多个互不相连的结构可以一起搬动，但不提供同时插入或同时吸附；须选择一个结构才能插接。
- 方向键微调采用相同的完整移动集合，避免键盘移动把鼠标移动保持的连接拆掉。
- Space 拖动继续平移画布；字段编辑、流程端口、引用操作不抢占数据拖动。

## 4. 快捷拔出

### 4.1 拖关系框拔出右侧尾段

关系框保留原样，单击仍在属性栏编辑运算符。按住并拖过阈值，才进入“从这里拔出”操作：

1. 固定原图、所选关系和原右侧尾段。
2. 草稿中只删除所选关系，右侧尾段整体跟手；其内部连接和运算符保留。
3. 左侧留在原处。原关系框消失，断口和被带走的范围短暂高亮。
4. 可以直接拖到别的合法端点或关系框接回，不必先松手到空白处。
5. 松手一次提交；Esc、指针取消或窗口失焦恢复原图，不写入半次操作。

```text
原来： A + B × C + D
拖 ×： A + B          [ C + D ] 随指针移动
```

选中关系框按 Delete 或在其菜单中执行“断开”，得到相同的结构结果；没有指针跟随时，由第 6 节确定尾段落点。

### 4.2 取出单个节点

建议提供 `Alt + 拖节点`，并在节点菜单提供“取出此节点”，用于单节点快速插拔：

- 只带走这个同层节点；若是子包络，则带走整个子包络及附件。
- 断开该节点左右两条数据关系，保留两边的节点和各自内部连接。
- 不自动把左右两段重新连接。比如从 `A - B × C` 取出 B，不能自行决定把剩余内容改为 `A - C` 还是 `A × C`。
- 在包络内发生时，保留原最左侧的剩余连通段，其他剩余段按第 6 节退出包络；若没有剩余成员，按现有空包络清理规则处理。
- 单节点取出与默认整体拖动有不同的预览范围；Alt 状态在拖动开始时固定，途中不切换模式。

## 5. 快捷接续与插入

### 5.1 接续空闲端点

从节点库拖出新节点，或拖动一个已有完整结构，把它的空闲端点靠近目标结构的空闲端点。只匹配“左端对右端”，不把节点中心靠近误判为接线。

一次只显示一个候选，预览包含新增关系、对齐位置和将要改变的包络范围。目标结构固定，以它为锚点安放被拖动结构；内部节点保持当前固定间距规则。

普通新增关系默认 `+`；合法的赋值位置显示 `← 赋值`。新增关系的运算符必须在预览中可见。类型不适合默认关系时，不显示可提交的吸附；用户可通过属性栏的显式连接操作选择合法关系。实现时需要保证显式连接入口可直接选运算符，不能要求先建立一个不合法的 `+` 再修改。

拖向包络内部成员的空闲端点，只有“连接成功 + 整段纳入该包络”同时成立才出现候选。拖到包络外侧端点，连接包络整体，保持同一父层级。落在包络空白处只改变位置，不改变归属。

### 5.2 插入已有关系

拖动一个节点或完整结构至已有关系框附近，预览替换后的完整局部结构。建议沿用原关系作为左边界，新右边界默认 `+`；被插入结构内部的关系不变。

```text
原来： A × B
插入： X + Y
结果： A × X + Y + B
       原 × 保留；X + Y 内部不变；新增右边界 +
```

该操作改变表达式含义，预览要显示两侧运算符和可计算的结果，继续遵循现有运算优先级。不会为了保留被插入片段的独立求值含义而自动加包络；需要分组时先把片段包络。

赋值插入单独处理：`v ← A` 插入 X 得到 `v ← X + A`，赋值仍指向 v。完整赋值结构不能插到普通表达式内部，避免生成多重赋值或把赋值目标当操作数。

两侧连接都合法才能提交；任一侧不合法则不给出插入候选，不覆盖目标。鼠标落在目标关系框命中范围内时优先插入；否则考虑端点接续。屏蔽移动集合自身、其后代，以及会产生环或跨层数据边的候选。

插入时左侧保留位置，原右段整体向右让位；包络按新内容调整大小，外层相邻数据节点按现有固定间距重新排列。预览和最终布局使用同一份计算结果。

### 5.3 吸附手感与释放规则

建议以 24 屏幕像素作为候选进入距离，以 36 屏幕像素作为当前候选退出距离，减少临界处闪烁。内部端点只有进入对应包络内容区域才参与候选，不凭大包络的面积抢占外侧端点。

同类候选按距离、明确命中的最内层目标、稳定 ID 排序；显示候选时同时标出接入层级。阈值是首版试用参数，审核实现后通过真实浏览器调整。

没有合法候选时，松手保留本次合法的移动/拔出结果，按游离结构放置。不能因为一次接入失败而丢失节点或只执行一半插入。新节点从库拖到画布外取消创建；已有节点拖到画布外取消本次拖动。Esc 始终恢复本次操作之前的完整状态。

## 6. 包络只容纳一个整体

### 6.1 创建与纳入

每个非空包络都只容纳一个连通整体。对于本稿重点设计的**数据包络**，其直属成员必须通过同层数据连接组成且只组成一个连通整体。嵌套包络按一个成员计算，并在其内部递归满足此规则。附件、引用线以及矩形位置重叠不算内部连通。

- 单个数据节点是合法整体，可单独包络。
- 选中同一条结构的一个或多个节点后执行包络，默认扩展到该层完整结构；命令提示显示将包络的完整范围。
- 选择多个独立结构或不同直属层级，拒绝创建，并提示“请先连接为一个整体，再包络”。不自动补线。
- 新的游离结构只有接到已有内部结构上，才随接线整体纳入。不能仅因为拖进矩形就成为成员。
- 若要包络原结构的一部分，先拔出该段，再包络和接回，使分组语义变化明确可见。

流程包络有分支与汇入，其直属成员按流程边组成一个连通整体，允许分支；检查连通时忽略边的方向，原有出口容量和无环要求继续适用。数据断线后的逐层退出也检查这种父层。流程包络不套用“横向最右端”的数据规则；本次收紧包络连通性，具体流程插拔手势保持现有规则。

### 6.2 内部断开：左留、右出

数据包络内部移除一条数据关系时，必须在同一次编辑中完成：

1. 按断开前的同层左右顺序划分左段和右侧尾段。
2. 左段保留在原包络，保留包络 ID、名称、附件及指向包络的引用；包络结果按左段重新计算。
3. 从原包络的 `members` 中移除右侧尾段的全部直属成员。尾段中的子包络、内部连接和附件完整保留。
4. 为尾段寻找合法归属和框外位置；不得出现“逻辑上已经移出，但画面仍被原框圈住”的提交结果。
5. 调整原包络大小及受其尺寸变化影响的相邻结构，一次性提交。

```text
断开前： E[ A + B × C + D ]
删除 ×： E[ A + B ]       C + D
                         ↑ 独立尾段，已在框外
```

如果断开的是赋值 `E[v ← A + B]`，得到 `E[v]` 和框外的 `A + B`。E 可能因此失去流程作用；已有流程/引用/附件若变得无效，保留对象并明确标错，阻止执行，不把它们悄悄接到尾段，也不删除用户节点。

### 6.3 嵌套包络：逐层退出

退出内层后不能直接把尾段塞进父包络，因为父包络也只能容纳一个整体。

规则：尾段只有在本次操作最终确实接入父包络的既有结构时，才能留在父包络；否则继续退出，直到某个祖先层级存在合法接入，或到达顶层。逐层只修改归属，不改写尾段的运算符，不自动新增连接。

```text
断开前： O[ P + I[ A + B ] + Q ]
断开 A + B 后默认：
         O[ P + I[ A ] + Q ]       B
                                  ↑ 顶层，不能孤立留在 O 内
```

如果直接把拔出的 B 吸附到 O 内部的合法端点，则最终把 B 纳入 O；原 I 中仅保留 A。此时删除旧边、改变归属、建立新边作为一个事务提交，中间态不写入存档。

### 6.4 尾段的落点

拖关系框拔出时，尾段按指针移动；若在原包络内部空白处松手且没有合法接入，自动调整到最终退出的最外层包络之外。预览提前显示实际落点。

通过 Delete/菜单断开时，默认在最终退出包络右侧留出 32 个画布单位；保持尾段内部相对位置，遇到其他结构则依次向下寻找可容纳空位。顶层断开原本没有包络时，尽量保留原坐标，仅留出可辨认的断口。

原左段的最左节点保持位置；尾段整体移动。空包络按现有删除规则清理；相关清理必须一起进入撤销记录。若一次删除多个节点/连接产生多段，保留原最左侧仍存在的连通段，其他各段分别退出，不把它们重新组合成一个假整体。

## 7. 临时反馈与历史

继续使用原节点、关系框和虚线包络，只增加操作期间的状态：待移动范围轮廓、断口高亮、半透明插入预览、目标包络范围与简短提示。常态尺寸、颜色体系、关系框位置规则、结果摘要位置和图层机制保持当前方案。

拖动期间只有草稿状态，不触发自动保存或多次历史记录。一次松手提交节点、连接、成员归属、位置及图层；撤销和重做精确恢复同一个状态。拖动期间收到外部文档变更时取消本次草稿，避免覆盖新文档。

拆出的尾段成为独立图层结构；按现有结构图层规则插入相邻次序。原包络和尾段不再因为残留 `members` 被当作一个结构。跨结构引用线只更新锚点。

## 9. 审核后验收场景

| 场景 | 必须观察到的结果 |
| --- | --- |
| 顶层 `A + B × C`，拖 C | 全结构同位移，运算符和数据连接不变 |
| `E[A + B]`，拖 B | 包络、成员、结果、附件一起移动 |
| `P + E[A + B] + Q`，拖 B | 按本稿选择，完整结构一起移动；预览准确标出范围 |
| 拖中间关系框 | 只断该边，右侧整段跟随，左侧固定 |
| `E[A + B × C + D]` 删除 × | E 只含 A、B；C、D 在框外且仍通过 + 相连 |
| 嵌套包络中断边 | 尾段不成为任何祖先包络内的第二个独立结构 |
| 拔出的段直接接入另一包络 | 原包络收缩，目标包络扩张，全段迁移且无跨层数据边 |
| `Alt + 拖 B`，原结构为 `E[A - B × C]` | E 留 A，B 被取出，C 移出；不擅自生成 A 到 C 的边 |
| 插入节点/整段到关系框 | 预览与提交一致，左右关系合法，右段完整让位 |
| 插入赋值关系、移除赋值关系 | 赋值目标不反转；流程作用变化有明确错误提示 |
| 把无连接节点放进包络矩形 | 不增加成员；不能伪造一个新的包络内结构 |
| 选中两个独立结构包络 | 拒绝创建，原图不变 |
| 25%、100%、300% 缩放 | 屏幕拖动阈值和吸附手感一致，实际落点与预览一致 |
| Esc、失焦、非法插入、撤销/重做、保存重载 | 无半次编辑，节点无丢失，归属、位置和图层可恢复 |

实现验证需要纯编辑逻辑测试和真实浏览器手势回归。本次仅交付设计稿，未运行或声称上述功能验收通过。

## 10. 本轮审核重点

1. 默认拖节点保持完整结构；通过拖关系框拔右段，通过 Alt 拖动取出单节点。
2. 包络内尾端整体移动时，包络及其外部数据连接一起跟随；需要局部移动时显式拔开。
3. 断线后左段留在原包络，右段逐层退出，最终必须处于合法归属且画面上在相应框外。
4. 插入时保留原左边界关系、新右边界默认 +；不自动补桥、不自动改变分组。
5. 所有包络只包含一个连通整体；数据包络按数据边判断，流程包络按流程边判断，引用和位置重叠不算连接。
