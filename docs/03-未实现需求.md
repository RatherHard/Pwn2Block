# Pwn2Block 未实现需求

下面是明确不属于当前 MVP、目前没有实现的需求。它们不是 MVP 缺陷；如要实现，应单独立项并重新定义安全和数据契约。

## 产品能力

- 用户注册、登录、角色和权限管理。
- 学习进度、历史成绩、云端保存和跨设备同步。
- 排行榜、赛事模式、团队协作和多人房间。
- 与外部 CTF 平台自动提交、成绩回传或嵌入式集成。
- 在线题目编辑器、题目审核流、版本发布和题目市场。
- AI 自动生成 exploit、自动解题或自动改写 payload。

## 平台与运维

- 多租户、独立 verifier 进程、任务队列和弹性扩缩容。
- PostgreSQL、Redis、对象存储等持久化基础设施。
- 完整审计日志、签名发布、协议版本协商、幂等键和分布式会话。
- 正式公网运营所需的认证、TLS 终止、配额系统、监控告警和备份恢复。

## VM 与调试能力

- 完整 x86/x86-64 指令集、ELF 装载、真实 shellcode 和真实系统调用。
- 堆分配器、多架构、ASLR、PIE、NX 等真实二进制运行特性。
- 任意断点、条件断点、checkpoint 和任意时间点跳转。
- 更复杂的多阶段状态机、自定义微操作和完整 IR/程序状态可视化。

## 前端与体验

- Blockly 的完整无障碍键盘导航。
- 其他浏览器和移动端的完整适配。
- 面向生产的性能拆包、长期压力优化和可观测性面板。
