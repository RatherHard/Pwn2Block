# Pwn2Block 需求文档（MVP）

本目录是 Pwn2Block 的 MVP 需求文档，只保留首个教学闭环需要的内容。

## 一句话定位

这是一个内存可视化的 Pwn 概念实验室。学习者用积木拼装 payload，交给后端权威 VM 执行，再观察栈、寄存器和指令的变化，在这个过程中学会栈帧、缓冲区溢出和返回地址劫持。

它不是浏览器里的 Linux 或 x86 模拟器。

## MVP 主要取舍

保留的部分：

- 后端权威 VM，浏览器只拿公开投影。
- VMA 内存模型，以及出题人可配置的位宽、寄存器、指令编码。
- Blockly 积木 payload。
- 四种内存视图。
- 分级提示和可解释错误。

舍弃的部分（MVP 不做）：

- 分发与接入机制：独立 verifier 进程、启动票据 / 嵌入协议、多租户、宿主成绩同步、admin 管理面。
- 会话协议的工程机制：revision 防重、幂等键、协议版本握手、规范化 JSON、状态哈希、签名发布链。
- 部署与运维：每会话独立进程加 NDJSON 引擎协议、PostgreSQL / Redis / MinIO、监控指标、CI 机检门禁。
- 引擎的高级特性：IR 程序形态（只保留字节形态）、自定义微算子指令、多阶段状态机、seed / ASLR、隐藏测试。
- 调试克隆通道：原有的“调试模式”整体舍弃。断点改由权威会话原生支持，见 04。
- checkpoint 和时间线：降为 P1，MVP 只做 undo / reset。

## 优先级约定

- **P0**：MVP 必须交付。
- **P1**：MVP 之后的第一批增强。
- **P2**：远期。

各文档未标注的条目默认为 P0。
