## 使用规则

- 了解当前实现，读 01、02；确定本轮目标，读 10；开始修改，读 00。
- 10 中涉及的交互与布局要求优先于历史设计，但“目标行为”不等于“当前行为”。
- 完成一个可验收部分后，更新实施记录与相关能力说明；全部验收完成后再将本轮需求标为已实现。
- 03、05 中的后续产品和历史债务按需另行排期，不自动扩入本轮。
- 已完成计划、旧设计、验收快照和被新需求替代的讨论稿放入归档，不继续作为开发任务入口。
