# Pwn2Block 文档

Pwn2Block 是一个用 Blockly 拼装 payload、由后端 VM 执行并可视化内存变化的 Pwn 教学实验室。本文档只保留实现和协作所需的决策；代码中的类型与 Schema 是字段级事实来源。

## MVP 的取舍

保留：后端权威 VM、VMA 内存模型、可配置位宽与编码、Blockly payload、五类调试视图、分级提示、可解释错误、调试回退和判题回放。

暂不做：用户登录和成绩同步、多租户、独立 verifier、数据库/缓存/对象存储、随机化布局、隐藏测试、断点和任意时间跳转、协议签名与状态哈希。

## 关键规则

- 调试实例可以反复试验但不发 flag；提交时重新回放，服务端判胜后才发 flag。
- flag 真值通过环境变量注入，仓库只保存 `env:FLAG_<ID>` 引用。
- 浏览器只拿公开投影；隐藏内存内容不能通过字段、错误或副作用泄露。
- 优先级：P0 是 MVP 必须项，P1 是下一批增强，P2 是远期规划。
