# 05 前端交互

前端只展示公开投影、编辑 payload 和发送动作；它不执行 VM，也不判题。真实状态和事件边界以 `packages/web/src/viewmodel`、组件测试和 [09-契约冻结](09-契约冻结.md) 为准。

## 工作台

页面由四层组成：

1. 顶部导航：品牌、视图菜单、运行菜单、调试/判题结果切换。
2. 题面卡片：可折叠的 `briefing` 和分级提示。
3. 状态区：当前模式、执行结果、错误、恢复和网络提示。
4. 主工作区：左右两栏。左栏是视图管理器，右栏是 payload 窗口；桌面端等宽，窄屏降为单列。

左栏同时显示两个视图槽位，其他视图通过纵向滚动切换。视图菜单支持显示/隐藏和调整顺序，`Ctrl+↑ / Ctrl+↓` 切换槽位。右栏按顺序显示 Blockly、程序区和输出区。

调试模式读取调试实例的当前投影；判题结果模式读取提交录像的选中帧。两种模式复用同一套视图，判题模式额外显示结论、flag 和回放时间线。

## 视图

- **栈**：按 W 字节显示，跟随 `sp`，标记 `bp`、返回地址、缓冲区和自定义标签；支持地址跳转、hex/ASCII 搜索和指针链。隐藏字节显示 `??`，未映射地址留空。
- **指令**：显示服务端投影的地址、机器码和伪汇编；`ip` 行高亮，函数/跳转目标可定位。前端不解码指令。
- **寄存器**：显示寄存器和 `ZF/CF/SF`，变化值高亮，点击值可复制。
- **内存**：显示公开 VMA 的范围、权限和 hex dump；隐藏 VMA 只显示布局。
- **I/O**：题目声明相关能力时显示 stdout、stdin、syscall 和 fd；新写入字节高亮。

视图只读取投影中已有内容，不提供任意地址读取，也不提供断点和可配置分屏。

## Payload 窗口

| 操作 | 作用 |
|---|---|
| 编译 | 在浏览器内把积木转换为原子动作序列 |
| 试运行 | 将剩余动作发送到调试实例 |
| 单步 | 发送下一个动作 |
| 运行 N 步 | 调试实例执行指定指令数，替代断点 |
| 后退一步 | 回退最近的单条指令，受历史窗口限制 |
| 撤销 | 回退上一次请求 |
| 重置 | 把调试实例和程序指针回到起点 |
| 提交判题 | 把完整动作序列发给判题实例并进入结果模式 |

顶部运行菜单和 payload 工具栏共用同一份按钮模型，禁用原因必须一致。编辑 Blockly 后产物标记为过期并重新编译；编译错误和被拒动作都能定位到积木。

编译结果只是一种便利，服务端仍会逐动作校验。循环、表达式、字节构造和动作数量都受 shared 常量限制；payload 不读取当前 VM 状态，偏移必须由学习者自行计算。

## 提示、错误和恢复

- 提示按顺序揭示；`unlockAfterFailures` 达标时自动解锁。手动揭示进度按题目 id 保存在本地，丢失不影响做题。
- 编译错误显示在输出区并高亮积木；服务端拒绝或失败时显示公开的 `message`、`note` 和可见定位。
- `satisfied` 只在调试模式提示“已满足”，不发 flag；执行实例退出后，执行类按钮禁用，回退和重置仍可用。
- 判题结果为 `won`、`incomplete`、`failed` 或 `rejected`，均提供录像回放；成功显示 flag，失败默认定位出错帧。
- 会话过期或网络错误时显示可理解的原因，并提供重新开始；刷新恢复程序、指针和服务端会话时不能混用新旧产物。

## 可访问性

所有按钮、菜单、折叠区、输入框和时间线可键盘操作；状态通过 `aria-live` 播报；颜色同时配合文字或符号；焦点环在深色背景上清楚可见。Blockly 的完整键盘导航属于后续增强。
