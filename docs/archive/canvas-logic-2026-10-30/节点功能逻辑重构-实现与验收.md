# 节点功能逻辑重构：实现与验收

实现基准为 `docs/节点功能逻辑重构.md`。此前的《节点画布大型修改》《节点画布 UI 与交互重构》不再约束当前画布；历史数据模型与对应测试仍保留，用于识别存档和验证兼容边界。

## 明确的语义

- 数据关系有方向。`a → b` 的运算结果为“a 的表达式结果 op b 的原值”，继续连线可组成链；包络选择唯一末端节点作为整体结果。通过包络表达括号优先级，不依靠屏幕坐标隐式改变运算优先级。
- 赋值连接必须指向变量。变量节点只有名称，不复制状态；同名节点访问同一个全局变量。流程内改值时，把赋值表达式包络并接入流程即可。
- 数据包络含赋值时同时具备流程身份，所以可与方法共同组成流程包络，循环可逐轮先更新变量、再调用方法。嵌套数据包络保留内层附着循环；向方法、分支和循环连接时默认建立数据引用，通过外置流程端口明确建立执行连接。
- 循环次数在进入循环时求值，支持 0 次。分支使用 bool 引用，选中的出口沿显式连接继续执行；合流节点只沿实际路径执行一次。
- 解除数据包络时，外部结果引用转接到内部唯一结果节点；无法确定连接端点时拒绝解除并提示调整，不静默删除引用。
- 附着转换先转换包络内部结果，再参与包络外部运算；读取转换节点与读取其包络得到一致结果。转换保留显式类型规则，无法表示或不支持的转换给出错误。string/bytes 的加法与拼接一致；数字不做隐式字符串拼接。
- 未接入开始流程的普通流程节点不执行；流程外赋值仍是全局定义。缺参数、错误类型在实际执行路径中阻止生成动作，派生变量写入和结构/依赖环在运行前拒绝。
- 新图最多 512 节点、2048 连接；动作、循环、步骤、字节值及求值次数沿用或收紧共享层预算。任一错误不发布部分动作。

## 存档与应用边界

外层保存格式仍为 v2，新图位于 `document.logic`，内部 `version=1`。新文档的旧 `nodes/layout/main` 为空。保存、导入、导出、切题和撤销都以整份图为单位。拖动期间替换文档会取消旧拖动；文件读取期间切题、编辑或发起新导入会使旧读取失效，避免覆盖后续工作。

旧模型与损坏存档保留供导出，不做有损推断迁移；归档状态禁止运行。用户点击“导出原存档并新建画布”后才开始新图。原有用户需求文档不由此次实现改写。

动作仍只来自题目公开方法；编译结果沿用应用外壳的动作、来源、错误、步骤和修订号接口。服务端仍负责权限、方法展开和最终判题。VM 单步等调试操作仍由顶栏提供。

## 维护入口

- `packages/shared/src/canvas/logic-model.ts`：图的 Schema 与分类。
- `logic-validate.ts`、`logic-runtime.ts`、`logic-values.ts`：校验、执行和值语义。
- `packages/web/src/canvas/logic-editor.ts`：几何、最近吸附、包络和不可变编辑。
- `packages/web/src/components/logic-canvas.ts`：手势和画布；`logic-canvas-fields.ts`：节点属性表单。
- `canvas-panel.ts`：文档、历史、存档与外壳事件；`canvas-panel-legacy-view.ts` 只参与历史兼容测试。
- `tests/e2e`：当前产品的真实浏览器回归，使用公开测试 flag。每个用例清理自己创建的会话，避免重复运行触发会话容量限制。

验证命令及本轮结果见 [浏览器回归手册](../../../tests/e2e/README.md)。
