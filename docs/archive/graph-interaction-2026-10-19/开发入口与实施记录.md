## 2. 本轮固定的产品决定

以下决定都已按需求落地，改动它们前先读 10 与 02：

- 视图在上、画布工作区在下；使用页面滚动，不设置可拖动分隔条。
- 左侧节点库、中央画布、右侧常驻展开的属性面板；常用参数可在节点内和面板内同步编辑。
- 首次进入且无可恢复内容时，画布没有任何节点，包括开始节点；保存的空画布能够正常恢复。
- 空白处左键拖动平移，Shift + 拖动框选；普通滚轮滚动页面，画布内 Ctrl + 滚轮缩放。
- 拖动和依次点击端口均可接线；支持改接、删除及撤销；正式和临时连线都用直角折线。
- 节点库按七类用途组织，最多两级，支持搜索、预览和拖拽添加。
- Python 代码在右侧面板内嵌编辑，支持扩大编辑区域；移除 Python 文件导入入口。
- 复用极简 TUI 主题；允许更换画布技术，但更换技术本身不是交付目标。

完整细节及边界以 10 为准。此处仅为阅读导航，不另维护一套需求。

## 5. 如何验证

### 按改动验证

- 编辑命令和坐标：优先使用 [graph-editor.test.ts](../../../packages/web/test/graph-editor.test.ts)、[graph-geometry.test.ts](../../../packages/web/test/graph-geometry.test.ts)。
- 组件与存档：参考 [graph-canvas.test.ts](../../../packages/web/test/graph-canvas.test.ts)、[graph-panel.test.ts](../../../packages/web/test/graph-panel.test.ts)、[graph-p8.test.ts](../../../packages/web/test/graph-p8.test.ts)。
- 执行与模块回归：按修改范围运行 `packages/web/test/workflow.*.test.ts` 和相关共享模型测试。
- 拖动、滚动、输入焦点、接线和真实布局必须用浏览器验证，不能只凭源码断言或纯函数测试判定通过。
- 浏览器运行前提与命令见 [E2E 说明](../../../tests/e2e/README.md)：先构建、启动真实后端，再设置 `PWN2BLOCK_E2E=1` 运行；默认跳过不算通过。

例如在仓库根目录运行与命令、几何有关的现有测试：

```powershell
pnpm exec vitest run packages/web/test/graph-editor.test.ts packages/web/test/graph-geometry.test.ts
```

### 交付检查

按 [仓库约定](../../../CLAUDE.md) 和 [CI](../../../.github/workflows/ci.yml) 运行所需检查。完整交付包括类型检查、lint、构建、相关单元与集成测试、题目校验和参考解法，以及真实浏览器 E2E。若改动 Python 协议或运行器，再执行相应 Python 与隔离验证。

本轮交付时的结果：`pnpm typecheck`、`pnpm lint`、`pnpm test`（132 个文件 / 1983 通过 / 5 todo）、`pnpm build`、`pnpm challenge:check ret2win`、`pnpm challenge:solve ret2win` 均通过；`pnpm e2e` 在干净后端上 17 个用例全过。逐项证据见 10 §10。未自动化的部分（多选拖动的浏览器用例、更窄宽度的真机视觉）在 [05](../../05-未完成工作.md) 里保留。
