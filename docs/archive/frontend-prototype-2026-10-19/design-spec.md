# 前端视觉规范

> 已归档（2026-10-19）。这是早期原型文档，不代表当前生产界面。文中的文件路径和命令按原型原位置理解；运行文件与截图仍在 [design/frontend](../../../design/frontend/README.md)。当前开发见 [00-开发入口](../../00-开发入口.md)。

版本：2026-10-15 / 单套深色终端风格。产品结构依据 docs/05 与 docs/10；本文件中的具体色值、留白、符号和尺寸是设计决策，不新增产品功能。主稿 1440×900，检查 1280×720 与 1920×1080。

## 1. 信息层级与布局

从上往下：62px 顶栏 → 可折叠题面 → 34px 数据源栏 → 等分工作区 → 判题专属时间线 → 27px 状态栏。原型额外的 42px 演示控制条独立放在最底部；接入产品时删去，释放空间给工作区。

工作区 `grid-template-columns: minmax(0,1fr) minmax(0,1fr)`，`gap:0`，两列本身无边框。背景层次区分两半，不插入中间边线、拖动手柄或留白。禁止用户调整左右比例。1440 宽各 720px，1280 宽各 640px，1920 宽各 960px。

左侧：43px 视图管理标题栏，剩余区域为垂直滚动视口。每个视图槽 `height:50%`，始终以两个槽位为单位展示；每槽再包含标题、工具条、可独立滚动的数据与简短说明。更多视图排列在同一纵向列表中。平滑滚动配合 `scroll-snap-type:y proximity`，不吞掉输入框里的 Ctrl+方向键。

右侧：画布区（含标题和两行工具栏）、程序区、输出区，顺序固定。主稿比例为 `minmax(0,2.3fr) minmax(110px,.7fr) minmax(105px,.65fr)`。小桌面按 `minmax(0,1fr) 100px 100px` 保留程序与输出，画布内部滚动。没有暂停操作。

题面收起后仍显示题目名、题号、位宽与提示计数。标题与主要按钮保持一行；长题面内部滚动，正文最大 84px，小桌面 56px。提示区域最多 128px，小桌面 76px。展开提示不会使提交或恢复入口掉到视口外。

## 2. Token

颜色在 `styles.css :root` 定义。迁移到 `theme.ts` 的 `:host`，保持现有 `--p2b-*` 名称。不要直接跨 Shadow DOM 依赖本原型全局选择器。

|---|---|---|
| `--p2b-bg` | `#0b0e0d` | 页面最深背景 |
| `--p2b-bg-alt` | `#0e1412` | 控件底色、顶栏 |
| `--p2b-panel` | `#131c18` | 内容面板 |
| `--p2b-raised` | `#1b2721` | 浮起层级参考 |
| `--p2b-line` | `#293a31` | 表格分隔、输入边线；不用于中间分屏线 |
| `--p2b-fg` | `#e0e9e2` | 正文、关键技术内容 |
| `--p2b-dim` | `#98aba0` | 解释、次级文字 |
| `--p2b-accent` | `#7ee787` | 主操作、当前 ip、通过文本 |
| `--p2b-changed` | `#ffd866` | 一次变化提示与 Δ |
| `--p2b-warn` | `#f0c76d` | 过期、不完整、等待 |
| `--p2b-error` | `#ff9088` | 错误说明、错误轮廓 |

| `--block-author` | `#b39fd6` | 出题人分类标记 |

积木填充用低饱和暗色，分类色只用于图例、边缘和输入槽。动作积木的暗玫瑰底色不能单独表达错误，错误必须叠加亮红轮廓、`!` 与文案。隐藏布局不是错误，使用 `◇ 隐藏`。

按 sRGB 相对亮度计算的代表性对比：正文/面板 14.02:1、次级文字/面板 7.18:1、强调/面板 11.32:1、错误/面板 7.95:1、主按钮深字/绿色底 11.03:1。这些数值只对应指定色对，不是对全页每个组合的无障碍认证。

| token / 规则 | 值 | 用途 |
|---|---|---|
| `--font` | Consolas → Cascadia Mono → Microsoft YaHei UI → ui-monospace → monospace | 本地字体，无下载；数字、地址、指令使用等宽拉丁字形，中文按系统回退 |
| `--text-body` | 13px / 1.6 | 页面正文 |
| `--text-sm` / `--text-xs` | 12px / 11px | 按钮、表格、解释 |
| 品牌 / 页面标题 | 19px / 16px | 控制在单行，避免占用调试空间 |
| `--space-1/2/3/4/6` | 4 / 8 / 12 / 16 / 24px | 组件节奏；主面板内边距 20px |
| `--control` | 30px | 主控件高度；次级 26px |
| `--row` | 32px；小桌面 27px | 数据行基准；含两行语义时自然增高 |
| `--radius` | 5px | 控件；标签 3px；菜单 7px |
| `--focus` | 2px solid `#80bfff`，外偏 3px | Tab 定位 |
| `--motion` | 160ms | 控件反馈；数据变化仅一次约 1000ms |

所有状态以文字或符号补充颜色。图形只使用轻量字符符号（箭头、三角、勾叉、列表），不引入图标字体、插画或持续闪烁装饰。

## 3. 组件状态

| 组件 | 普通 | 悬停 / 焦点 | 禁用 / 等待 | 错误 / 特殊 |
|---|---|---|---|---|
| 主提交按钮 | 实心绿色 + 中文标签 | 提亮 / 蓝色外轮廓 | 灰绿、禁用；来源栏显示等待 | 编译过期、无产物时不可提交 |
| 调试按钮 | 暗底细边 | 边线提亮 / 2px 焦点 | 请求期间全部串行锁；结果模式禁用 | failed/exited 禁执行，允许有效回退 |
| 模式切换 | `aria-pressed` + 填充 | 同按钮 | 无结果时结果入口禁用 | 结果来源栏紫色 + “只读回放” |
| 视图菜单 | checkbox、拖动柄、上下按钮 | 可见焦点 | 首项上移/末项下移禁用 | 全隐藏显示空态和恢复入口 |
| 字节行 | 对齐表格 | 可点击地址提亮 | 隐藏内容仅 `??` | 变化 Δ；未映射为空“—” |
| 积木 | 可见连接缺口与输入槽 | tooltip / 蓝色选择轮廓 | 结果模式字段只读 | 红色轮廓、错误气泡、输出定位 |
| 程序行 | 行号 + 动作 + 参数 | 点击定位积木 | 过期仍保留旧产物作对照 | 当前位置箭头；拒绝行“× 拒绝” |
| 输出 | 时间与动作说明 | 定位按钮 | 等待说明，不提供暂停 | message / note 分开；不补编不存在的原因 |
| 回放 | 帧号 + 动作名 + 滑块 | 拖动/方向键 | 首尾箭头禁用 | 默认选失败帧，拒绝帧保留前一投影 |
| 复制 | 清晰标签或可点击值 | 焦点可见 | 剪贴板不可用则提供手动复制文字 | 只有 won 区域呈现示例 flag |

禁用原因同时放在 title 与就近状态说明。生产接入应把具体禁用原因通过 `aria-describedby` 关联，不能仅依赖鼠标 tooltip。主要操作仍需通过原生 disabled 阻止重复触发。

## 4. 视图细节

栈每行 W 字节，样例 W=8。地址、hex、ASCII、标签和值分列显示，数字采用 tabular-nums。buffer、saved_bp、ret_addr 的邻接关系不能被排序打乱。对齐偏移 0…W−1，搜索只查公开已有内容。`sp/bp` 标签由角色映射生成；执行后只滚动栈表内部以跟随 sp。

指令使用地址、机器码、投影提供的伪汇编三列。ip 行有左侧标记和箭头。函数下拉来自公开 `labels.kind=func`，跳转目标来自 `disasm.target`。没有断点列，也不在浏览器解码机器码。

指针链最多 3 跳，标明终点；进入可执行区显示投影中的伪汇编，进入隐藏/未映射则停止。链上的普通公开字节只能显示 ASCII/hex，不能把非指针强行继续解析。

寄存器从 `projection.registers` 逐项生成；样例的 RAX/RDI/RSP/RBP/RIP/FLAG 不构成固定产品架构。ZF/CF/SF 始终有文字和值。点击值复制，反馈在全局播报区与轻量通知内。

自由内存 VMA 列表显示 id、kind、label、范围、perm 与 hidden。范围为半开区间。公开 VMA 选中显示 hex dump；隐藏 VMA 不绘制虚构字节，只显示 `??` 说明。未映射内容为空，不渲染成零，也不渲染成 `??`。

I/O 仅在公开题目声明 syscalls 或 fds 时出现；stdout ASCII/hex 切换，新增部分以 Δ/新增 B 标记；stdin 按 pos 分割，已读部分灰色加划线说明。速查包括公开 ABI、调用号、名称、doc 与 fd 权限。未声明 stdout/stdin 时应分别显示“未声明”，不是请求隐藏内容。

## 5. 画布与编译

四类工具箱保持“通用 / 字节 / 动作 / 出题人积木”顺序。字节类覆盖 padding/string/int/addr/raw/concat；动作按 allowedActions；出题人积木按公开声明与参数类型生成输入槽。开始块唯一，未连接块带“未连接·不参与编译”说明。没有运行时读寄存器/内存块、列表或返回值函数。

连接和阴影是 HTML/CSS 外观说明，不是可用 Blockly 编辑器。H 接入真实 Blockly 时沿用分类色、低饱和填充、中文参数名、12px 左右文本、清楚的连接缺口、蓝色选中轮廓与独立红色错误轮廓。tooltip 不遮住正在编辑的输入槽；feed 必须明确提示“放在触发读取的 step/run 之前”。完整画布键盘导航仍为 P1。

程序状态：尚未编译 → 编译成功 → 正在执行 → 已执行完；编辑后转已过期；编译失败没有可执行产物。过期时保留上一成功产物，禁止把新参数假装已经编译进旧动作。错误信息与 blockId 关联，循环/表达式/动作上限均说明限制并提供定位。

## 6. 调试、判题与恢复

调试 satisfied 只呈现“当前状态已满足成功条件”，引导正式提交；动作仍可用，不出现 flag 或判胜依据。failed/exited 保留公开状态与错误解释，执行禁用但可回退。历史为空与 64 条窗口之外分别解释，实际可退深度由响应 history 决定。

四种结果使用同一工作台与视图；独立结果横幅明确 won/incomplete/failed/rejected。只有 won 显示 flag；当前设计样例始终附带“示例，非真实 flag”。incomplete 强调 payload 还未完整，不把它说成语法错误。failed 选择出错帧；rejected 标动作拒绝、积木关联与投影未改变。

时间线为“初始投影 + 逐动作帧”。一个 run 可以执行多条指令，不能用动作帧数冒充指令数。拖动时所有视图共用所选公开快照。返回调试保留原调试投影、payload 位置与历史；生产中还要保留编辑画布并冻结提交时的来源映射。

无可用题目时显示独立的题目列表空态与刷新入口，不绘制伪造的题面或开始积木，调试操作禁用。加载时使用静态占位与“正在加载公开投影”；无视图、无产物、无输出分别给出下一步。网络/404 提示会话失效并提供重新开始；创建新会话后清空调试历史，保留本地画布和已揭示提示。当前原型没有实现刷新后的真实 GET 会话恢复。

## 7. 溢出与可访问性

表格不截断地址或机器码；宽内容横向滚动，表头粘性定位。动作 hex 和长错误按字符换行，程序/输出各自滚动。长题面独立滚动，不推走工作台。画布可在自身二维滚动区域内定位；选择错误积木后只滚到其可见位置。主桌面之外不新增移动流程；小于 1000px 使用工作台最小宽度，移动端不在验收范围。

页面中文 lang，关键操作有中文标签。模式用 `aria-pressed`；折叠与菜单用 `aria-expanded`；状态变化进入单独的 `aria-live=polite` 区域，避免整个表格重复播报。所有按钮、菜单输入、原型参数和时间线使用原生键盘交互。定位后焦点移动到目标块；Escape 关闭菜单并还焦到菜单按钮。拖动排序提供等价按钮。`prefers-reduced-motion:reduce` 下禁用动画和平滑滚动。

已验证的是浏览器 DOM、焦点属性与几何行为；真实读屏、实际视觉审查、不同系统中文字体与真实 Blockly 接入需要后续验收。
