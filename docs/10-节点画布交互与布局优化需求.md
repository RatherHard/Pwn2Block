## 1. 目标与范围

让节点画布成为主要操作区：用户可以直接添加节点、修改常用参数、建立和调整连接、查看节点状态，也可以使用常驻属性面板编辑同一节点。

本轮交付包括：

- 修复节点起拖瞬移和拖拽时意外选中文字的问题。
- 将视图与画布改为上下排列，使用页面滚动浏览。
- 完善画布平移、框选、缩放、接线与改接操作。
- 支持节点内编辑与属性面板编辑同步。
- 整理节点库分类，增加搜索、预览与拖拽添加。
- 首次打开题目时提供空画布。
- 移除 Python 文件导入入口，提供内嵌代码编辑器。
- 统一极简 TUI 视觉，使用直角折线表达连接。

本轮允许调整画布技术实现，但不以更换技术栈作为交付目标。

## 2. 页面布局

### 2.1 上下工作区

视图窗口在上，节点画布工作区在下，两者使用页面可用宽度。视图保留现有的视图切换方式。

```text
┌──────────────────────────────────────────────────────┐
│ 视图窗口                                             │
│ 保留现有视图切换方式                                 │
├──────────────────────────────────────────────────────┤
│ 节点库       │ 节点画布                 │ 属性面板   │
│ 分类与搜索   │ 节点、参数、端口和连线   │ 当前节点   │
│              │                          │ 完整配置   │
└──────────────────────────────────────────────────────┘
```

- 不设置可拖动分隔条，不要求两个工作区同时完整塞进一屏。
- 页面保持正常纵向滚动；鼠标位于画布上时，普通滚轮仍滚动页面。
- 工作区应有足够的可操作高度，不能依靠压缩节点内容来适应一屏；具体尺寸在实现时结合现有主题确定。
- 左侧节点库和右侧属性面板属于下方画布工作区。
- 右侧属性面板常驻，默认展开；选中节点后展示该节点的配置，未选中时显示简短提示。
- 画布平移只改变节点视野，不承担页面上下滚动的职责。

### 2.2 节点内编辑与属性面板

- 数值、文本、下拉选项等常用参数在节点内直接编辑，属性面板也提供对应编辑控件。
- 两处编辑同一份数据，修改后同步显示；校验规则与提示内容一致。
- 同一次参数修改只形成一条撤销记录，不因同步两个界面而重复记录。
- 复杂配置在属性面板中提供完整编辑入口，节点内保留必要摘要与配置入口。
- 输入端口旁显示参数名称；已连接参数显示上游来源，明确区分手填值与连接输入。
- 沿用现有手填与连接输入的切换语义，同一参数在两个编辑位置显示相同模式；切换模式及连接变更应同步反映。
- 节点标题区用于拖动。输入框内编辑、选择或复制文字时，不触发节点移动或画布快捷操作。

## 3. 画布操作

### 3.1 鼠标与键盘规则

| 操作 | 行为 |
|---|---|
| 空白处按住左键拖动 | 平移画布 |
| 按住 Shift，在空白处拖动 | 框选节点 |
| 拖动节点标题栏 | 移动节点；该节点已在多选集合中时，一起移动选中节点 |
| 操作节点内输入框、下拉框 | 正常编辑，不触发节点移动 |
| 普通滚轮 | 滚动页面，包括鼠标位于画布上时 |
| 画布内按住 Ctrl 滚动滚轮 | 以鼠标位置为中心缩放画布 |
| 拖动端口，或依次点击两个端口 | 建立连接，支持从输入端或输出端发起 |
| 选中连线后按 Delete | 删除该连接 |
| 拖动已有连线的端点 | 改接连接 |
| 按 Esc | 取消当前接线、改接或框选操作 |

提供缩放按钮和适应画布入口。画布内的 Ctrl + 滚轮由画布缩放处理，避免同时触发页面缩放；画布外保留正常浏览器行为。编辑控件拥有焦点时，Delete 等按键保持其文本编辑含义。

### 3.2 拖动稳定性与文本选择

- 无论画布当前如何平移或缩放，开始拖动时节点保持原位，随后按鼠标位移移动。
- 拖动保持鼠标与节点的初始相对位置，不将节点原点瞬间吸附到鼠标位置。
- 多选拖动保持各节点之间的相对位置。
- 移动节点、平移画布、框选、从节点库拖入节点及拖拽接线期间，禁止意外选中文字。
- 拖拽结束或取消后恢复正常文本操作；不能全局禁用输入框、代码编辑器或可复制内容的选择能力。

### 3.3 接线与改接

- 拖拽连接和点击连接均为完整支持的操作方式。
- 可以从输入端或输出端发起，最终连接方向始终为输出到输入。
- 起拖或第一次点击后，显示临时折线并突出兼容端口。
- 点击接线模式下，第二次点击兼容端口完成连接；按 Esc 或点击空白处取消。
- 尝试连接不兼容端口时，给出明确原因，不生成无效连接。
- 连接到已有连接的单输入端口时，替换原连接；替换作为一次可撤销操作，撤销后恢复原连接。
- 已有连线可选中、删除，也可拖动端点改接。
- 改接取消或落到无效位置时，保留原连接；只有成功完成改接才替换原连接。
- 连接、删除、替换和改接应支持现有撤销与重做能力。
- 本节优化连接交互，不改变现有数据类型、作用域及控制结构的合法性规则。

### 3.4 输入输出与路径

- 数据输入端位于节点左侧，数据输出端位于右侧，显示端口名称和类型。
- 使用箭头标明连线方向，颜色与形状辅助识别，不仅依靠颜色区分输入输出。
- 数据连接与执行顺序在视觉上保持可辨识；不因改用折线而改变现有执行顺序或增加新的执行语义。
- 正式连线和接线中的临时连线统一使用直角折线。
- 拖动节点时实时更新连接路径；连线不得穿过其连接的节点本体。
- 选中节点或连线时突出相关连接关系。
- 自动绕开所有其他节点的全局路径避障未纳入本轮必交范围，后续如需增加，应单独明确验收标准。

## 4. 节点库

### 4.1 分类与搜索

按用途分类，最多两级。节点较多时再拆分二级目录，不为所有分类强制增加第二级。

| 一级分类 | 归类内容 |
|---|---|
| 数据与常量 | 整数、文本、字节、题目公开常量等 |
| 运算与判断 | 算术、比较、布尔逻辑、类型转换等 |
| 字节与载荷 | 填充、拼接、打包与解包、定位序列等 |
| 流程与变量 | 开始、分支、循环、变量声明与读写等 |
| 交互动作 | 当前实际支持的动作节点 |
| Python | Python 数据处理节点及代码模板 |
| 我的模块 | 用户封装和保存的可复用模块 |

以上是归类规则，具体节点按现有清单整理，不因分类名称而自动增加新的计算或交互能力。继续遵循题目权限与学习阶段的可用性限制。

- 记住目录展开状态。
- 提供节点搜索，结果直接列出匹配节点与所属分类路径。

### 4.2 预览与添加

- 鼠标悬停或键盘聚焦节点条目时，显示只读预览。
- 预览包含实际节点样式、用途简介、输入输出类型和默认参数。
- 预览不执行 Python 或其他求值；拖拽开始后关闭预览，避免遮挡落点。
- 以拖拽添加为主要方式，从节点库拖到画布时显示放置预览，松开后在落点创建节点。
- 节点创建位置应正确考虑画布平移、缩放和页面滚动，不出现落点偏移。
- 保留点击添加与键盘可达的添加入口；点击添加的新节点应位于当前可见画布范围内。

## 5. 空画布与保存恢复

- 首次打开某道题目且没有可恢复内容时，画布为空，不预置节点骨架，包括“开始”节点。
- 可显示简短的添加指引，但指引不是节点，也不写入图数据。
- 已有保存内容时，恢复用户的节点、连线、参数和布局。
- 用户主动删除全部节点后，空画布仍能保存；再次打开时保持为空，不补回默认节点。
- 将“没有存档”与“存档内容是空画布”区分处理。
- 若执行模型要求开始节点，则在运行或校验时提示添加，不自动插入。空画布可编辑、可保存，不代表能作为合法流程执行。
- 存档恢复及现有旧格式迁移继续遵循既有约定；损坏存档不能被当作首次进入而静默覆盖为空画布。

## 6. Python 编辑体验

- 移除导入 Python 文件的入口，以内嵌代码编辑器编辑 Python 节点。
- 选中 Python 节点后，在右侧属性面板直接编辑代码，并配置命名输入和输出类型。
- 编辑器提供语法高亮、行号、自动缩进和 Tab 缩进。
- 支持临时扩大代码编辑区域；退出扩大状态后回到原布局，保留编辑内容。
- 代码与输入输出配置随画布保存、恢复。
- 画布中的 Python 节点显示输入输出、代码摘要和求值状态；错误能关联到对应节点。
- 求值状态沿用现有求值机制，不能仅因打开编辑器或查看节点库预览就执行代码。
- 本轮调整代码编辑入口与体验，沿用 Python 仅处理数据、显式输入输出及既有后端求值边界。
- 移除 Python 文件导入不影响整个画布或模块的既有导入导出能力。

## 7. 极简 TUI 视觉方案

复用项目主题，通过排版、边框和状态反馈改善可读性。

| 部位 | 视觉要求 |
|---|---|
| 节点外观 | 直角矩形、细边框、等宽字体；标题区和参数区使用细线分隔 |
| 节点标题 | 名称突出，配置入口位置固定，拖动区域可辨识 |
| 参数区域 | 标签与输入框对齐；接线参数显示来源；长内容截断并可查看全文 |
| 端口 | 显示名称与类型，形状辅助区分类型 |
| 连线 | 直角折线、方向箭头；默认低对比度，选中后突出关联关系 |
| 节点状态 | 用明确的边框或文字标记区分选中、执行中、错误，颜色作为辅助 |
| 画布背景 | 沿用主题底色，使用低对比度、稀疏的点阵辅助定位 |
| 工具栏 | 紧凑文字按钮，集中放置撤销、重做、缩放和适应画布等操作 |
| 节点库预览 | 复用实际节点样式，保持拖入前后的结构一致 |

继续遵守项目极简 TUI 约定：无渐变、阴影或装饰性圆角。低对比度元素仍应可辨认，选中与错误状态不能只靠颜色传达。

## 8. 实施约束

- 以交互体验和本文件验收条件评估现有画布实现是否适用，允许更换技术，不预先指定框架或库。
- 若更换技术，应在实施前验证节点内输入、常驻面板同步、直角折线、双模式接线、拖拽坐标与页面滚动的兼容性，并记录技术决策。
- 保留现有图模型、编译求值、执行与判题语义；若必须调整存档结构，应提供兼容方案，不能丢失用户已有内容。
- 保留已有模块、控制结构、预览定位及键盘可达能力；新交互应与这些能力协调。
- 各区域具体高度和宽度、二级分类明细、编辑器与画布库选型属于实施细节，以满足本文件行为要求为准。

## 9. 验收标准

| 编号 | 场景 | 通过条件 |
|---|---|---|
| A01 | 页面布局 | 视图在上、画布工作区在下；没有可拖动分隔条；页面可正常纵向滚动，右侧属性面板默认展开 |
| A02 | 双入口参数编辑 | 节点内和面板内均能修改常用参数，值、输入模式和校验提示同步；撤销一次即可撤回一次修改 |
| A03 | 节点拖动 | 默认、缩放后、平移后以及页面滚动后起拖均无瞬移；多选移动保持相对位置 |
| A04 | 文本选择 | 各类拖拽不意外选中文字；结束或取消后能正常选择、复制参数和代码 |
| A05 | 平移与框选 | 空白处左键拖动平移，Shift + 拖动框选；输入框编辑不触发拖动 |
| A06 | 页面滚动与缩放 | 画布上普通滚轮滚动页面；Ctrl + 滚轮围绕鼠标缩放画布，不同时缩放页面；缩放按钮和适应画布可用 |
| A07 | 双模式接线 | 拖动及依次点击端口均能连接，输入或输出端均可发起；有临时折线和兼容提示；取消后不残留连接 |
| A08 | 接线合法性 | 不兼容连接显示原因，不生成非法边；箭头始终表达输出到输入 |
| A09 | 连接替换与改接 | 单输入端口替换、选中删除和端点改接均可用且可撤销；改接取消或落点无效时保留原连接 |
| A10 | 连线显示 | 正式与临时连线均为直角折线，有方向标识；节点移动时实时更新，不穿过所连接节点本体；选中时关联关系突出 |
| A11 | 节点库 | 按七个一级分类组织，目录最多两级，展开状态可恢复；搜索结果带分类路径；符合题目可用性限制 |
| A12 | 预览与添加 | 悬停和键盘聚焦可查看只读预览；拖入时显示落点，页面滚动、画布平移缩放后放置仍准确；点击及键盘入口可用 |
| A13 | 首次进入与空存档 | 无可恢复内容时完全空白，无开始节点或其他骨架；删除全部节点并保存后再次进入仍为空 |
| A14 | 保存恢复 | 已有节点、连线、参数、代码和布局正常恢复；损坏存档不被静默覆盖；缺少开始节点在运行或校验时提示且不自动补入 |
| A15 | Python 编辑 | 文件导入入口移除；面板编辑器具备高亮、行号及缩进；命名输入和输出类型可配置；扩大再恢复不丢内容，代码随图保存 |
| A16 | Python 反馈 | 节点展示摘要、输入输出和求值状态；错误定位到节点；仅打开编辑器或节点库预览不会触发求值 |
| A17 | TUI 与可用性 | 直角、等宽字体、细边框与主题一致；状态不只靠颜色区分；在原有最低验收尺寸 1280×720 下可通过页面滚动完成添加、编辑、接线及执行，控件不被裁切到无法操作 |

本轮验收应覆盖上述用户操作，同时确认既有执行结果、模块能力与存档恢复没有因界面调整而回退。
