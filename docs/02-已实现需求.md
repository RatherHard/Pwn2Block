# Pwn2Block 已实现需求

以下记录当前已实现能力，包括 MVP、节点画布、Python 数据处理与交互布局。历史需求和阶段验收见 [归档目录](archive/README.md)，工程待办见 [05-未完成工作](05-未完成工作.md)。

## 学习者能力

- 浏览题目公开说明和公开内存布局。题面和提示按 Markdown 子集渲染：`#`–`######` 标题、段落、代码块、`>` 引用、有序和无序列表（最多 3 层嵌套）、`---` 分隔线，以及粗体、斜体、行内代码和链接；链接只显示文字，不生成外链，原始 HTML 和无法识别的标记按原文显示。
- 返回题目列表并切换题目，保留各题画布并接回仍有效的调试会话。题目列表（`/`）和题目页（`/challenges/<id>`）各有地址，刷新、前进后退和分享链接都落到对应页面；不存在的题目显示「题目不存在」。
- 创建、查询、删除会话，并在会话中反复调试。
- 查看栈、指令、寄存器、内存（含 VMA）和标准 I/O 等状态。视图区一次只显示一个视图，用固定标签切换（本题没有 I/O 时不显示该标签）；标签栏支持 ←/→/Home/End，页面上任意非输入位置可用 Ctrl+↑/↓ 循环。当前标签存在浏览器本地 `p2b:view-tab`，所有题目共用，读取失败或值非法时回到「栈」。
- 题目带伪代码时，可在视图区的「伪代码」标签页查看出题人写的伪代码（等宽、只读，按 C 语法着色：注释、预处理指令、字符串、数字、关键字、类型、函数名）；没有伪代码的题目不显示该标签。
- 使用 `write_bytes`、`push`、`pop`、`call`、`ret`、`feed`、`step`、`run`、`undo`、`step_back`、`reset` 等动作。
- 在节点画布中组合 padding、字节、地址、原子动作、控制流、模块和题目积木。
- 改动节点后在浏览器内自动编译为受限的原子动作，也可点「编译」重跑；编译错误列在页面底部的输出区，点击「定位」会展开容器并选中问题节点。没有独立程序区。
- 点 payload 标题栏的「运行」执行整段 payload：先 `reset`，再按单次请求上限分片发送完整动作序列，末尾不补 `run`，与提交判题回放的是同一份序列；画布为空时发 `reset` + `run`。运行中可点「终止」，它只在浏览器侧停止发送后续分片，已发出的请求照常生效，状态栏显示「已终止：执行到动作 n/m」。单步、运行 N 步、后退、撤销、重置和提交判题在顶栏「运行」菜单里。在输出区和状态栏查看失败原因、错误定位、状态变化和回放录像。
- 逐级查看提示；提示和节点画布可以按题目保存在浏览器本地。
- 提交 payload 进行独立判题；判胜后查看并复制 flag，失败后回到调试继续修改。
- 刷新页面后恢复已有服务端状态和前端程序指针（在会话仍有效时）。

## VM 与安全能力

- 可配置位宽、寄存器、VMA、权限、指令编码和成功/失败条件。
- 实现教学需要的栈操作、调用/返回、内存读写、指令执行、快照、回退和回放。
- 支持受控的 `read`、`write`、`exit` 等 I/O/syscall 语义和虚拟文件。
- hidden memory 只在服务端执行，公开投影不包含隐藏字节。
- 调试和判题使用独立 VM 实例；提交从初态回放，不能借用调试时的手工操作。
- 动作、payload、请求体、编译展开、I/O 和资源使用均有边界校验。
- 未声明动作或 syscall 会被拒绝；失败动作不会产生未声明的副作用。
- 服务端负责最终校验，浏览器编译器不承担安全职责。

## 题目与工程能力

- 六道 MVP 题目包与后续新增的 `ret2rop` 均包含公开题面和服务端私有材料。
- `challenge:new`、`challenge:asm`、`challenge:check`、`challenge:solve` 出题工具链可用。
- 题目 flag 使用环境变量注入，缺少 flag 时题目不会被加载。
- 题目可附带 `pseudocode.c` 伪代码，随公开包下发；服务端加载和 `challenge:check` 校验 UTF-8 / LF（仅出题侧）、长度上限，并拒绝含 flag 占位符或真值的伪代码。`challenge:new` 不生成该文件。`ret2rop` 已提供伪代码，其余六道题暂未提供。
- Fastify API 和构建后的前端静态资源可以由单进程提供。
- 已有单元、集成、验收和浏览器 E2E 测试覆盖核心闭环、边界和安全契约。

## 节点画布与 Python 数据处理（P0–P9 已完成）

节点画布与 Python 数据处理的实施状态见 [07-实施计划](archive/graph-2026-10-19/07-节点画布与Python数据处理实施计划.md) 与 [08-技术决策](archive/graph-2026-10-19/08-节点画布技术决策.md)。目前已落地：

- **图模型**：`GraphDocument`（节点、参数、数据连线、执行序列 `main`、布局）有 zod Schema 与版本号，解析失败给出可定位的问题列表；节点种类按阶段列出，参数与端口由节点规格派生。
- **编译管线**：`compileGraph` 是异步、可取消的纯本地计算：按依赖求值数据节点（整数、字节、地址、拼接、十六进制、算术、比较、位运算、截取、组装、条件选值等），按执行序列生成既有动作协议；成功给出完整产物（动作、来源、预览、追踪），失败列出带节点 id 的错误，绝不发送半成品。求值与动作额度沿用 `packages/shared/src/limits.ts`。
- **画布与编辑**：节点画布是默认且唯一入口（工具箱、画布、检查器、编译状态）。支持加删节点、拖动、框选、数据端口拖线、类型/成环校验、双击线断开、执行端口拖动调整顺序、撤销重做、复制粘贴、键盘接线与快捷键；文档按题目存浏览器本地，坏存档显示原因并保留原文，不会静默退回空图。容器可以折叠（只改布局、可撤销，双击容器或检查器切换），折叠后子节点、区域框与相关连线一起隐藏；缩放低于阈值时隐藏端口名与副标题，只留节点骨架。
- **分支、循环与变量（P4）**：`control.if`（含「否则如果」链）、`control.repeat`、`control.while/until` 是占据执行位置的容器，子序列存在 `regions` 里；`control.result` 给出容器结果，声明了结果的容器必须在每条可达路径末尾都有结果。`control.break`/`continue` 作用于最近一层循环，`control.index` 给从 0 开始的本轮序号，`control.accumulator` 读上一轮累计值，零次循环结果等于初始值。变量按作用域静态校验（重复声明、未声明、类型不符），运行时按层解析并在赋值后更新缓存版本。循环每轮重算动态依赖（缓存键含作用域、轮次和变量版本），整图共享求值/轮次/动作预算；容器在画布上画出区域框，可把语句拖进区域或「移出容器」，这些编辑都可撤销。
- **Python 求值服务（P6）与节点接入（P7）**：服务端新增求值接口与隔离运行器，后端可配置为 `none`（默认，明确报不可用）、`docker`（唯一可声称隔离的后端）或 `process`（仅开发，`isolated=false`）；超时、内存、输出、并发、排队与每次编译次数均有上限。运行器自带常用打包与定位序列工具，服务端校验请求后只回值或节点级错误码。画布面板读取 `GET /api/capabilities` 并显示后端与隔离状态；编译经可替换的 `PythonEvaluator` 发 `POST /api/python/eval`，带整图取消信号，语义编辑会取消在途请求，迟到结果不覆盖新产物。没有可用求值器时 Python 节点明确报 `python_unavailable`，不会退回浏览器执行。内置「生成定位序列」「查找序列偏移」与 Python 侧同名工具共用 `shared` 的字母表、宽度与编码规则。

- **模块调用与提取（P5）**：`GraphDocument.modules` 里可以定义数据模块与流程模块（类型化输入、默认可选值、说明、固定版本），调用节点 `module.data` / `module.call` 钉住 `id + 版本`，编译期把模块体展开进当前序列，动作与来源照常生成；模块体有独立作用域与求值缓存，两次调用互不污染，求值步数、循环轮次与 Python 次数仍与主图共享。校验拒绝缺失版本、种类不符、端口不一致、直接/间接递归与超过 4 层的嵌套，数据模块里出现动作或控制结构直接报错。画布可从选区「提取为模块」：要求同一区域连续、容器选全、至多一个外部数据消费者，外部输入/输出改写成调用端口，整步可撤销；选区含动作或控制结构时生成流程模块（可以没有结果），否则生成数据模块。调用节点在检查器里可「升级到 vN」，先比对输入集合、结果有无与类型、调用节点声明的端口，不兼容就拒绝并保留原版本；新版本不会自动影响已有调用。工具箱会列出已定义模块（名称、版本、调用次数），点一下插入填好参数的调用节点。点面包屑或双击调用可进模块体编辑，返回后主图恢复；来源定位会切进对应模块实例。画布支持分组：选中两个以上节点即可框成一组，组只影响显示，不改变执行顺序，删除节点后自动裁掉悬空成员。参数可从「手填」切到「接线」：手填会断开该端口连线，接线缺线时编译报错，手填却仍有线只给警告；按偏移组装的节点逐段显示偏移、长度与来源。
- **存档迁移与来源定位（P8）**：存档是带格式、版本、题目、固定版本依赖与文档的包装（`pwn2block.graph-save`），按题目写入独立新键 `pwn2block.graph.v1.<challengeId>`；早期裸文档键和旧 Blockly 键只读保留。旧 Blockly workspace 按白名单单向转换，变量、控制、字节与动作语义尽量保留，不支持项整体拒绝并给出原因，迁移失败不清空也不覆盖原文，可导出 JSON。定位支持节点、模块实例、分支路径和循环轮次，只改布局（展开容器/模块、切视图、选中目标），不重算语义；编译轨迹与数据分段可点击高亮，执行/判题高亮绑定当时的产物版本，编辑后不会误指新图。判题时间线明确是历史录像，不用当前图重算，也不承诺重放 Python。
- **运行链路与验收（P9）**：画布编译成功后把动作与来源写进同一个产物追踪器，运行、单步、提交、终止沿用原控制器与分片规则；语义编辑会标记产物过期并取消在途请求。Blockly 界面、`payload-panel.ts` 与运行时依赖已删除。真实浏览器 E2E 覆盖画布构造 payload、错误提交、判胜、刷新恢复、编译错误定位、坏存档保留，以及 1280×720 / 1440×900 / 1920×1080 三尺寸布局与键盘路径。

## 节点画布交互与布局

当前行为如下。原始需求与阶段验收保存在 [交互布局归档](archive/graph-interaction-2026-10-19/README.md)，后续调整以本节为准。

- **布局**：视图在上、画布工作区在下，高度随窗口尺寸和比例调整，页面正常纵向滚动。宽屏工作区为「节点库 / 画布 / 属性面板」三栏；宽度不超过 800px 时属性面板移到画布下方。选中节点显示完整属性，未选中显示提示。
- **属性统一侧栏编辑**：画布节点只显示属性值与端口，不提供输入框、下拉框、「配置」按钮或额外的「选中」文字。属性面板修改和撤销会同步画布；接线属性显示来源，缺线时显示「未连接」，长值可悬停查看完整内容。
- **手势**：空白处左键拖动平移，Shift + 拖动框选，标题栏拖动节点（多选一起移动并保持相对位置），普通滚轮滚页面，Ctrl + 滚轮以指针为中心缩放，缩放按钮与 `f` 适应画布。拖动预览使用绝对图坐标，避免连续拖动或缩放后的跳变；画布拖拽不选中文字，侧栏输入框仍可选择和编辑文本。
- **接线**：拖拽与点击—点击都支持，输入或输出端都能发起；临时折线高亮兼容端口，Esc / 空白处取消。单输入端口被占用时新连接替换旧的，替换、删除、改接都是一条可撤销记录；无效落点保留原连接并给出原因。端口属于当前选中连线时，拖动该端口就是改接。
- **连线呈现**：正式线与临时线共用正交路由（只有 `M/L`，每段同行或同列），按端口类型着色并带箭头；拖动节点实时重算路径，选中连线时线加粗、相邻节点高亮。
- **节点库目录**：仅有「分类 → 节点列表」两级，分类包括数据与常量、运算与判断、字节与载荷、定位序列、流程控制、循环、变量、交互动作、Python、我的模块，隐藏空分类。根目录面包屑保留「节点库」，不重复显示独立标题；子目录顶部在面包屑下显示返回按钮，宽度与节点选项一致。
- **节点库预览与权限**：每个节点常驻显示只读预览，不触发求值；去除标签中括号，高亮选项使用深色文字。动作依照题目 `allowedActions` 过滤，题目积木来自 `authorBlocks`，搜索、点击添加和拖入均执行权限检查。拖入落点考虑平移、缩放和页面滚动，点击添加落在当前可见区域内。
- **空画布**：首次进入没有节点（含「开始」），只显示添加指引；空画布可保存、刷新后仍为空。缺「开始」在编译时提示而不自动补节点；损坏存档仍锁定原存档，不回退也不覆盖。
- **Python 编辑**：保留 Python 处理节点，移除 Python 模板与文件导入入口。侧栏代码框与其他组件对齐，支持高亮、行号和缩进；扩大编辑时，编辑器占用中央画布区域。返回按钮或 Esc 保存内容并恢复画布视野与选择，代码随图保存。Tab/Enter 等由编辑器改写文本的操作也会立即提交，错误定位到节点。
- **TUI 视觉**：节点直角细边框、等宽字体，标题区与参数区用细线分隔，端口显示名称与类型并用形状区分，状态用边框与文字而不只靠颜色，画布用稀疏点阵辅助定位；`tui-style.test.ts` 约束渐变、阴影、圆角与内联 HTML。
