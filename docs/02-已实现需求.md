# Pwn2Block 已实现需求

以下记录当前已实现能力，包括 MVP、节点画布与交互布局。历史需求和阶段验收见 [归档目录](archive/README.md)，工程待办见 [05-未完成工作](05-未完成工作.md)。

## 学习者能力

- 浏览题目公开说明和公开内存布局。题面和提示按 Markdown 子集渲染：`#`–`######` 标题、段落、代码块、`>` 引用、有序和无序列表（最多 3 层嵌套）、`---` 分隔线，以及粗体、斜体、行内代码和链接；链接只显示文字，不生成外链，原始 HTML 和无法识别的标记按原文显示。
- 返回题目列表并切换题目，保留各题画布并接回仍有效的调试会话。题目列表（`/`）和题目页（`/challenges/<id>`）各有地址，刷新、前进后退和分享链接都落到对应页面；不存在的题目显示「题目不存在」。
- 创建、查询、删除会话，并在会话中反复调试。
- 查看栈、指令、寄存器、内存（含 VMA）和标准 I/O 等状态。视图区一次只显示一个视图，用固定标签切换（本题没有 I/O 时不显示该标签）；标签栏支持 ←/→/Home/End，页面上任意非输入位置可用 Ctrl+↑/↓ 循环。当前标签存在浏览器本地 `p2b:view-tab`，所有题目共用，读取失败或值非法时回到「栈」。
- 题目带伪代码时，可在视图区的「伪代码」标签页查看出题人写的伪代码（等宽、只读，按 C 语法着色：注释、预处理指令、字符串、数字、关键字、类型、函数名）；没有伪代码的题目不显示该标签。
- 使用 `write_bytes`、`push`、`pop`、`call`、`ret`、`feed`、`step`、`run`、`undo`、`step_back`、`reset` 等动作。
- 在节点画布中拼装标量常量、运算/赋值/拼接、类型转换、变量、包络与流程，并调用题目公开的方法积木；方法参数只能是字节串、整数或地址，展开由服务端完成。
- 改动节点后自动重新编译为受限的公开方法动作（每次变化都重编，修订号 +1，没有单独的「编译」按钮）；编译错误按节点列在输出区，点「定位积木」会滚到那个节点并选中。没有独立程序区。
- 点画布顶栏的「运行」执行整段 payload：先 `reset`，再按单次请求上限分片发送完整动作序列，末尾不补 `run`，与提交判题回放的是同一份序列；画布为空时发 `reset` + `run`。运行中可点「终止」，它只在浏览器侧停止发送后续分片，已发出的请求照常生效，状态栏显示「已终止：执行到动作 n/m」。单步、运行 N 步、后退、撤销、重置和提交判题在顶栏「运行」菜单里。在输出区和状态栏查看失败原因、错误定位、状态变化和回放录像。
- 逐级查看提示；提示和节点画布可以按题目保存在浏览器本地。
- 提交 payload 进行独立判题；判胜后查看并复制 flag，失败后回到调试继续修改。
- 刷新页面后恢复已有服务端状态和前端程序指针（在会话仍有效时）。

## VM 与安全能力

- 可配置位宽、寄存器、VMA、权限、指令编码和成功/失败条件。
- 实现教学需要的栈操作、调用/返回、内存读写、指令执行、快照、回退和回放。
- 支持受控的 `read`、`write`、`exit` 等 I/O/syscall 语义和虚拟文件。
- hidden memory 只在服务端执行，公开投影不包含隐藏字节。
- 调试和判题使用独立 VM 实例；提交从初态回放，不能借用调试时的手工操作。
- 动作、payload、请求体、编译展开、I/O 和资源使用均有边界校验。
- 未声明动作或 syscall 会被拒绝；失败动作不会产生未声明的副作用。
- 服务端负责最终校验，浏览器编译器不承担安全职责。

## 题目与工程能力

- 六道 MVP 题目包与后续新增的 `ret2rop` 均包含公开题面和服务端私有材料。
- `challenge:new`、`challenge:asm`、`challenge:check`、`challenge:solve` 出题工具链可用。
- 题目 flag 使用环境变量注入，缺少 flag 时题目不会被加载。
- 题目可附带 `pseudocode.c` 伪代码，随公开包下发；服务端加载和 `challenge:check` 校验 UTF-8 / LF（仅出题侧）、长度上限，并拒绝含 flag 占位符或真值的伪代码。`challenge:new` 不生成该文件。`ret2rop` 已提供伪代码，其余六道题暂未提供。
- Fastify API 和构建后的前端静态资源可以由单进程提供。
- 已有单元、集成、验收和浏览器 E2E 测试覆盖核心闭环、边界和安全契约。

## 节点画布（功能逻辑重构）

当前以 `archive/canvas-logic-2026-10-30/节点功能逻辑重构.md` 为唯一功能基准，取代此前“节点画布大型修改”和“节点画布 UI 与交互重构”的产品规则。

- **节点库**：左栏按“数据节点 / 流程节点 / 题目方法”分级进入，提供返回分类；每页最多 4 项，上一页/下一页显示边界禁用状态。节点外观预览与说明常驻各自选项中，点击添加。普通窗口左栏宽 280px，较窄窗口调整为 230px / 210px。
- **界面与菜单**：按钮不添加装饰性文字方括号；画布、侧栏和工具栏右键打开 TUI 菜单，撤销/重做与工具栏共享整图历史。支持方向键、Home/End、Enter、Esc/Tab；外部点击、滚轮、窗口失焦/尺寸变化关闭菜单，靠近视口边缘自动避让。输入框保留浏览器原生编辑菜单。
- **数据**：常量可编辑五种标量；变量只有名称，同名节点共享绑定，首次赋值确定类型。转换可直接填值或附着数据包络；支持显式字节宽度、大小端和有符号参数。不提供列表、字典节点。
- **全局定义**：流程外的赋值表达式在开始前初始化；引用其他变量的定义自动成为派生变量，随依赖变化、只读且依赖不可成环。类型不符或求值失败阻止生成整份动作。
- **流程**：唯一开始；条件分支接受 bool 引用并提供 true/false 两个出口；次数循环附着包络，使用手填 int 或 count 引用；公开题目方法以流程节点出现。
- **包络**：虚线框包含同类成员，可嵌套、整体移动、解除。数据包络提供括号结果；带赋值的数据包络可进入流程，也可与方法共同组成流程包络。循环和转换有可见附件标识。引用可以跨越包络边界。
- **连接**：运算、赋值、拼接用带文字且按关系配色的小框，点击后在右侧切换。`string * int` 和 `bytes * int` 表示重复片段（如 `"ab" * 3` 得到 `"ababab"`）；次数必须为非负整数，0 次得到同类型空值，结果沿用文本/字节大小上限。流程使用分离方形端口和实线直角路径；引用使用三条平行实线。流程端口支持点击起点后点击终点接线。
- **吸附**：拖动期间只显示最近的一个合法候选，半透明预览随远离消失，松手才提交。吸附内部同类节点会纳入其包络；跨类引用保留各自归属。多层包络内部的连接不阻止整体吸附，流程引用使用拖动的最外层包络结果；已有跨边界连接（包括附件连接）的结构不自动重复吸附。新建节点寻找空位，避免连续新增时互相覆盖。
- **编辑**：Shift 多选、空白框选、包络、删除、Ctrl+G/A/Z/Y、方向键微调（4px，Shift 20px）、Esc 取消；字段统一在右侧编辑。删除包络会清理成员和附件；删除最后一个成员也会清理空包络。
- **执行反馈**：自动编译、错误定位、执行步骤与每轮变量快照。输出动作、来源和修订号继续交由外壳处理运行、终止、判题及恢复。
- **存档**：v2 包装内保存 `logic.version=1` 的连接图，支持导入、导出、按题自动保存与刷新恢复。旧模型或损坏存档保留原文，需导出并新建后才能继续编辑运行，不做有损自动迁移。

编译预算和大小限制沿用共享层：图最多 512 节点、2048 连接；循环、动作、变量值和求值都有上限。旧模型组件只参与兼容测试，生产入口固定使用新的逻辑画布。

逐项实现与测试入口见 [实现与验收](archive/canvas-logic-2026-10-30/节点功能逻辑重构-实现与验收.md)，浏览器实测命令见 [E2E 手册](../tests/e2e/README.md)。
