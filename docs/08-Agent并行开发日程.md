# 08 Agent 并行开发日程

> 编排基准：2026-10-15。当前仓库只有需求与工程文档，尚无 `packages/`、题目包和可运行工具链。
> 本文是执行计划，不替代 01–07 的需求定义。所有开发任务默认未完成；仅在真实验收通过后勾选。

## 1. 排期假设与使用方法

- **规模**：6 个固定职责角色，最多 6 个 agent 同时工作；不是为了占满并发而强行派任务。
- **周期**：15 个开发工作日，D1 为实际开工日，不代表连续自然日。日期暂不锁定；这是初始估算，不是交付承诺。
- **交付范围**：01 §3 的完整 MVP，首题 `ret2win`，总计先交付 6 道题。第 7–8 道是数量扩展，不挤占必需功能和安全测试。
- **执行策略**：契约先行；独立模块可用契约样例提前开发，正式接入仍遵守 07 §3 的依赖顺序。
- **勾选规则**：`[ ]` 未验收，`[x]` 已验收。进行中、阻塞、待集成写在任务记录里，不用勾选表示“代码已写”。
- **证据规则**：完成任务需留下提交号、检查命令和结果；mock 通过不能代替真实引擎、真实 API 或参考解法验证。
- **延期规则**：关卡未通过，依赖它的集成任务顺延；其他 agent 做独立任务、负例和文档，不绕过关卡。

## 2. Agent 职责与文件归属

以下目录是计划中的写入边界，D1 建立骨架时落实。一个文件在同一批次只能有一个写入者。

| 角色 | 主责 | 默认独占写入范围 | 不应自行修改 |
|---|---|---|---|
| A：集成 / 契约 | 工作区、shared、接口协调、合并与发布 | `packages/shared/**`、根配置、锁文件、CI、`docs/**`、本日程 | 不替其他角色顺手重构实现 |
| B：VM 引擎 | 内存、解码、执行、syscall、回退基础、纯判题回放 | `packages/engine/**`，含该包测试 | HTTP、页面、shared 契约 |
| C：服务端 | 题目加载、会话、公开投影、REST、静态托管 | `packages/server/**`，含该包测试 | 引擎内部状态实现、前端 |
| D：前端 | Lit 页面、视图、Blockly、客户端编译、交互 | `packages/web/**`，含该包测试 | 私有题目、服务端判胜逻辑 |
| E：出题工具 / 内容 | 汇编器、校验器、CLI、编码表、题目 | `packages/authoring/**`、`presets/**`；题目另开独立任务 | 在出题任务里修改引擎或工具 |
| F：独立验收 | 黑盒安全、集成验收、Playwright、回归证据 | `tests/acceptance/**`、`tests/e2e/**` | 修复其他角色的实现、根测试配置 |

协作约束：

1. A 在 D1 接通根级测试目录与脚本；各包自己的测试由包 owner 编写，不能全部等 F 补。
2. 新依赖先由 owner 提出，A 统一更新清单和 `pnpm-lock.yaml`，避免多人同时刷新锁文件。
3. 改 shared 契约先交 A；由 A 协调暂停受影响文件的写入，收齐消费者适配，在**同一提交**中更新类型及已存在的 server/web 等消费者，禁止半成品契约进入主线。
4. 文档语义修改由 owner 提供说明，A 同步修改 02/03/04 等事实来源，并随实现一起集成。
5. agent 各用独立分支和 worktree，不在同一个 checkout 并发切分支或提交。这里只规定后续执行方式，不在制定日程时创建。
6. 当前尚无 remote：用本地分支与集成提交协作；配置 remote 后执行仓库的 PR 规范。只由 A 集成到主线。
7. 出题任务单独使用 `challenge/<id>` 分支，只改 `challenges/<id>/`。工具链问题另建任务，不混入出题提交。
8. B 提供无 HTTP 依赖的提交回放能力供 server 与 `challenge:solve` 复用；CLI 不调用服务端，不复制一套判题逻辑。具体接口在 G0 冻结。

## 6. 安全验收勾选表（对应 07 §5）

以下测试由 F 独立验收，实现缺陷回到对应 owner 修复。不能只通过代码审阅打勾。

- [ ] 隐藏 VMA 的 write_bytes，以及读取隐藏栈槽的 pop/ret 返回 `hidden_address`，状态不变且不泄漏内容。
- [ ] 隐藏 VMA 投影只有布局、没有 hex；disasm 不覆盖隐藏区；无虚拟文件内容、win/fail 谓词。
- [ ] reveal 被 undo/step_back 回退后重新隐藏，stdin 位置、stdout、文件读偏移一起恢复。
- [ ] read/write/copy 任一字节越权即整体 `memory_fault`、无副作用；count 超过 0x1000 截断。
- [ ] feed 超过 stdin 4KB 被拒绝；stdout 超过 4KB 报 `resource_limit`。
- [ ] syscall 调用号不在表内时报 `invalid_instruction`。
- [ ] 隐藏 VMA 或虚拟文件包含 flag 真值时拒绝加载题目。
- [ ] 调试投影永远不含 flag 字段，包括 satisfied 状态。
- [ ] 调试满足成功条件只提示，不发 flag、不记录通过。
- [ ] 客户端提供的 block 展开结果不被信任，由服务端重新展开。
- [ ] 伪造判胜或提交快照的请求被拒绝。
- [ ] 不在 allowedActions 中的执行/写入动作被拒绝，回退动作按约定仍可用。
- [ ] payload 出现读状态积木时返回 rejected，不静默转换成零。
